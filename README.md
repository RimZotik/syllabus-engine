# Syllabus Engine

**Платформа и метод для создания строгих интерактивных курсов с ИИ-преподавателем.** Курс строится от конечного результата: кем должен стать ученик → что для этого нужно знать → учебный план от нуля, где каждая тема опирается только на пройденное. Платформа запускается локально и даёт:
- теорию, которая читается как хорошая книга: страницы, визуализации, термины со справкой;
- тесты, контрольные и экзамены с устным опросом у преподавателя Claude;
- песочницы с автопроверкой и интервальное повторение;
- пайплайн проверки каждого нового блока независимыми ИИ-ревьюерами: логика, факты, язык.

Движок не привязан к предмету: учебный план, темы, тесты и глоссарий лежат отдельно в `content/`. Поэтому так же можно собрать курс по музыке, рисованию или языкам — см. [«Как сделать такой же курс»](#как-сделать-такой-же-курс-по-другой-теме).

## Пример в разработке: Forge ML

Сейчас на движке строится первый курс — **Forge ML**: машинное обучение и работа с данными с нуля до уровня Junior+ ML-инженера, дата-сайентиста и AI-инженера. Курс 0 «Введение» и шесть курсов; 23 предмета с уровнями (Программирование I–VI, Алгоритмы I–VI и др.). Каждая библиотека «открывается» только после того, как ученик реализовал её идею сам. Полный план — [docs/content/curriculum.md](docs/content/curriculum.md); он генерируется из `content/program.yaml`.

> Статус: **этап 1 — фундамент платформы и первые темы.** Уже работают:
> - учебный план, чтение тем по страницам, тесты;
> - заметки, замечания к курсу, журнал ошибок.
>
> Тренажёр, песочницы и преподаватель — следующие этапы.

## Запуск

Нужны [Node.js](https://nodejs.org) 20+ и [uv](https://docs.astral.sh/uv/) (он сам поставит нужный Python).

```
npm install
npm run dev
```

Откройте http://127.0.0.1:5173. Прогресс и заметки хранятся в `~/.forge-ml/` — вне репозитория.

| Команда | Что делает |
|---|---|
| `npm run dev` | Сервер и веб-приложение в режиме разработки |
| `npm run check` | Проверка учебного плана и контента, типов и тестов сервера |
| `npm run feedback` | Открытые замечания к курсу — от ученика и преподавателя |

## Как сделать такой же курс по другой теме

Отдайте своему ИИ-агенту [docs/template/project-brief.md](docs/template/project-brief.md) — полную выжимку замысла: от конечного результата к учебному плану, требования к курсу и платформе и порядок работы с проверками. Скажите: «Сделай так же, но по направлению X». Устройство движка — в [docs/template/new-domain.md](docs/template/new-domain.md).
