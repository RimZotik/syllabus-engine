# Forge ML

Локальная интерактивная платформа и строгий курс «с нуля до Junior ML Engineer / Data Scientist»: теория простым языком с визуализациями, песочницы с автопроверкой (Python, SQL, Git, терминал, математика), интервальное повторение по концептам и наставник Claude.

> Статус: **этап 0 — концепция**. Платформа ещё не реализована.
