# Syllabus Engine

**Платформа и метод для создания строгих интерактивных курсов с ИИ-преподавателем.** Курс строится от конечного результата: кем должен стать ученик → что для этого нужно знать → учебный план от нуля, где каждая тема опирается только на пройденное. Платформа запускается локально и даёт:
- теорию, которая читается как хорошая книга: страницы, визуализации, термины со справкой;
- тесты, контрольные и экзамены с устным опросом у преподавателя Claude;
- песочницы с автопроверкой и интервальное повторение;
- пайплайн проверки каждого нового блока независимыми ИИ-ревьюерами: логика, факты, язык.

Движок не привязан к предмету. Каждое обучение — отдельный **пакет** в `courses/<id>/`: учебный план, темы, тесты, задачи, глоссарий, тексты главной страницы и свои демонстрации. Какой пакет открыт, задаёт одна строка в `courses/active.yaml`. Главная, «Обучение», «Зачётка» и преподаватель подстраиваются под пакет сами. Поэтому так же можно собрать курс по музыке, рисованию или языкам — см. [«Как сделать свой курс»](#как-сделать-свой-курс).

Полный план — [courses/ml-bigdata-ai/docs/curriculum.md](courses/ml-bigdata-ai/docs/curriculum.md); он генерируется из `courses/ml-bigdata-ai/program.yaml`.

> Тренажёр, песочницы и преподаватель — следующие этапы.

## Запуск

Нужны [Node.js](https://nodejs.org) 20+ и [uv](https://docs.astral.sh/uv/) (он сам поставит нужный Python).

```
npm install
npm run dev
```

Откройте http://127.0.0.1:5173. Прогресс и заметки хранятся в `~/.syllabus-engine/` — вне репозитория, у каждого пакета обучения свой файл.

Сменить обучение: в `courses/active.yaml` указать `active: <папка в courses/>` и перезапустить `npm run dev`.

| Команда | Что делает |
|---|---|
| `npm run dev` | Сервер и веб-приложение в режиме разработки |
| `npm run check` | Проверка всех пакетов обучения, типов и тестов |
| `npm run build:docs` | Пересобрать документы активного пакета (план, деревья предпосылок) |
| `npm run feedback` | Открытые замечания к курсу — от ученика и преподавателя |

## Как сделать свой курс

1. Формат пакета обучения — [docs/template/course-package.md](docs/template/course-package.md). Образец — `courses/ml-bigdata-ai/`.
2. Как описать желаемый курс обычными словами — [docs/template/course-brief-guide.md](docs/template/course-brief-guide.md). Готовый промпт для Claude Code — [docs/template/course-generator-prompt.md](docs/template/course-generator-prompt.md). Агент исследует источники, составит план, напишет темы и тесты, проведёт всё через проверки и подключит пакет.
3. Готовый пакет из другого репозитория подключается копированием папки в `courses/` и строкой `active:` в `courses/active.yaml`.

Если предмету нужна своя песочница (нотный редактор, холст), это изменение движка — [docs/template/new-domain.md](docs/template/new-domain.md). Полная выжимка замысла проекта для своего агента — [docs/template/project-brief.md](docs/template/project-brief.md).
