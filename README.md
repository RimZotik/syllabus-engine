# Forge ML

Локальная интерактивная платформа и строгий курс «с нуля до ML-инженера и дата-сайентиста»: теория как в хорошей книге — с визуализациями и подсказками терминов, песочницы с автопроверкой (Python, SQL, Git, терминал, математика), интервальное повторение по концептам и преподаватель Claude, который принимает экзамены.

> Статус: **этап 0 — концепция**. Платформа ещё не реализована.

## Структура курса

Курс 0 «Введение» и 6 курсов; 23 предмета с уровнями (Программирование I–VI, Алгоритмы I–VI и др.) → 58 дисциплин → 163 раздела → 355 тем; около 2 000 часов вместе с проектами. Каждая библиотека «открывается» только после того, как ученик реализовал её идею сам.

Полный план: [docs/content/curriculum.md](docs/content/curriculum.md) (генерируется из `content/program.yaml`).

## Документация

Путеводитель: [docs/README.md](docs/README.md). Разделы:

- **product** — цель, методика, преподаватель Claude
- **content** — учебный план, стиль текстов, форматы файлов, визуализации, источники
- **platform** — архитектура движка, план разработки
- **frontend** — дизайн-система
- **template** — как сделать такую же платформу для другого направления

Макет интерфейса: откройте [design/mockup/index.html](design/mockup/index.html) в браузере.

## Проверка учебного плана

```
uv run --with pyyaml tools/program/build.py          # проверить порядок и пересобрать docs/content/curriculum.md
uv run --with pyyaml tools/program/build.py --check  # только проверить (для CI)
```
