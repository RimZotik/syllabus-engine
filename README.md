# Forge ML

Локальная интерактивная платформа и строгий курс «с нуля до ML-инженера и дата-сайентиста»: теория как в хорошей книге — с визуализациями и подсказками терминов, тесты и устные ответы, песочницы с автопроверкой, интервальное повторение и преподаватель Claude, который принимает экзамены.

> Статус: **этап 1 — фундамент платформы и первые темы.** Работают учебный план, чтение тем по страницам, тесты, заметки, замечания к курсу и журнал ошибок. Тренажёр, песочницы и преподаватель — следующие этапы.

## Запуск

Нужны [Node.js](https://nodejs.org) 20+ и [uv](https://docs.astral.sh/uv/) (он сам поставит нужный Python).

```
npm install
npm run dev
```

Откройте http://127.0.0.1:5173. Прогресс и заметки хранятся в `~/.forge-ml/` — вне репозитория.

| Команда | Что делает |
|---|---|
| `npm run dev` | Сервер и веб-приложение в режиме разработки |
| `npm run check` | Проверка учебного плана и контента, типов и тестов сервера |
| `npm run feedback` | Открытые замечания к курсу — от ученика и преподавателя |

## Структура курса

Курс 0 «Введение» и 6 курсов; 23 предмета с уровнями (Программирование I–VI, Алгоритмы I–VI и др.). Каждая библиотека «открывается» только после того, как ученик реализовал её идею сам. Полный план — [docs/content/curriculum.md](docs/content/curriculum.md), он генерируется из `content/program.yaml`.
