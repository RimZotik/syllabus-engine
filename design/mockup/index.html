Модуль 2 · Линейная алгебра · Урок 6

Умножение матриц — это «сделать одно, потом другое»

Матрица — это не просто таблица чисел. Это инструкция, как сдвинуть плоскость: повернуть, растянуть, наклонить. Когда мы умножаем матрицы, мы склеиваем две такие инструкции в одну.

Пример из жизни: сначала повернуть фото на 90°, потом растянуть по ширине — это не то же самое, что сначала растянуть, потом повернуть. Поэтому AB ≠ BA.
Интерактив: двигай ползунки — смотри, куда уходят базисные векторы

В ML это встречается везде: слой нейросети — это умножение на матрицу весов, а глубокая сеть — цепочка таких умножений.

Композиция преобразований

Напиши функцию compose(*mats), которая возвращает одну матрицу, эквивалентную применению всех преобразований по порядку (сначала первая). Используй только @, без циклов по элементам.

Дано: модуль numpy as np уже импортирован. Входы — квадратные матрицы одного размера.

Тесты

compose(I) == I
compose(R90) == R90
compose(R90, S) == S @ R90
скрытые тесты: 5
Подсказка 1 из 3 · концепт. Векторы умножаются справа: M @ v. Какая матрица должна стоять ближе к вектору — та, что применяется первой?
solution.pyPython 3.12 · Pyodide
1def compose(*mats): 2 """Матрица, равная применению mats по порядку.""" 3 result = np.eye(mats[0].shape[0]) 4 for m in mats: 5 result = result @ m # порядок? 6 return result
попытка 3 · правок 41
AssertionError: compose(R90, S) ≠ S @ R90
Логика, а не синтаксис: результат корректной формы, но порядок множителей обратный.
