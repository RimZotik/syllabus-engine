# Пакеты обучения

Каждая папка здесь — отдельное обучение (пакет) для платформы Syllabus Engine. Какое из них открывает платформа, задаёт `active:` в `syllabus.yaml` в корне репозитория.

| Папка | Что это |
|---|---|
| `forge-ml/` | Forge ML — машинное обучение и работа с данными с нуля до Junior+ |
| `example-drawing/` | Маленький образец пакета: основы рисования, несколько тем — для тех, кто делает свой курс |

Формат пакета и подключение — [docs/template/course-package.md](../docs/template/course-package.md).
