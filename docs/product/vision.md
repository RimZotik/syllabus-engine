# 01. Цель и итоговый результат

> Подход «от результата»: сначала фиксируем, кем ученик должен стать к концу курса, потом выводим, что для этого нужно пройти и сдать.
> Данные о рынке собраны в ноябре 2026. Пометка **[оценка]** значит, что цифра выведена из общих знаний и требует перепроверки.

## 1. Кто есть кто: роли простым языком

| Роль | Чем занимается каждый день | Что сдаёт как результат |
|---|---|---|
| **Data Scientist (DS)** | Анализирует данные, проверяет гипотезы, проводит A/B-тесты, строит модели-прототипы (скоринг, отток, прогноз) | Выводы для бизнеса, прототипы моделей, решение «катить или нет» |
| **ML Engineer (MLE)** | Доводит модели до продакшена: признаки, пайплайны, сервинг, скорость, мониторинг, переобучение. По сути инженер на Python | Модель, которая работает внутри продукта |
| **LLM / AI Engineer** | Строит продукты на LLM: RAG, агенты, оценка качества, дообучение (LoRA), API-сервисы | LLM-функции в продакшене |
| **Data Engineer (DE)** | ETL/ELT, хранилища, Spark, Airflow, Kafka, качество данных | Надёжные датасеты для всех остальных |
| **MLOps** | CI/CD для моделей, Kubernetes, MLflow, мониторинг | ML-платформа |

**Уточнение к исходной постановке.**
- «Встроить языковую модель в бизнес, сделать RAG-базу» — это **LLM/AI Engineer**, подвид ML Engineer. Это самая быстрорастущая ниша, но классическое ML (табличные модели, бустинги) по-прежнему основная работа MLE и DS.
- «Собрать, очистить, подготовить данные» — частично **Data Engineer**, частично DS. А «раздуть датасет поворотами и отражениями» называется **аугментация** — это приём из ML (компьютерное зрение), а не Big Data.
- DS и MLE разделяют около 70% фундамента: Python, SQL, математика, классическое ML, валидация. Поэтому курс строится как **общий ствол + ветки**.

### Почему курс один для всех этих ролей

На практике границы размыты: в одной компании ML-инженер чистит данные и пишет SQL, в другой дата-сайентист выкатывает модель в прод, а «AI-инженер» строит RAG поверх хранилища данных. Поэтому курс не выбирает одну роль, а даёт **общий суперсет**: Python, SQL, математику, данные, классическое ML, нейросети, LLM, RAG и агентов, продакшен и большие данные. RAG и аугментация — полноценные разделы с собственными реализациями с нуля (см. курсы III и V в [curriculum](../content/curriculum.md)).

## 2. Реальность рынка (без иллюзий)

- Джуниор-вакансий в ML/DS мало: на одну джун-позицию в ML/DS приходится около 11 джун-позиций в других областях (анализ 2,6 млн вакансий, Coresignal).
- Главный вход в ML в России — **стажировки** больших компаний. Яндекс набирает около 500 ML-стажёров за сезон, 56% остаются в штате.
- Зарплаты (Habr Career, руб./мес. до вычета налогов):

| Роль | Junior (p25–p75) | Middle (медиана) |
|---|---|---|
| ML-разработчик | 75–150 тыс., среднее 115 тыс. | ~212 тыс. |
| Data Scientist | 90–155 тыс. | ~220 тыс. |
| Data Engineer | медиана ~140 тыс. | ~220 тыс. |
| Джун в бигтехе (Яндекс, Т-Банк, Сбер, Ozon, Avito) **[оценка]** | 150–250 тыс. | — |

- **300 тыс.** — это уровень сильного middle (около p75), обычно 2–3 года опыта или стажировка в бигтехе с последующим ростом. На старте реалистичная цель — **стажировка или джун в сильной компании**, откуда до 300 тыс. ведёт самый быстрый путь.
- Фактор, сильнее всего повышающий шансы джуна: **крепкий SQL и инженерный Python** поверх ML. Запасные входы — аналитик данных и Data Engineer.

## 3. Целевой профиль выпускника (суперсет)

Один профиль, который проходит отбор и на Junior MLE, и на Junior DS:

1. **Python как инженер**: типизация, тесты, Git, структура пакета, чистый код (PEP 8).
2. **SQL**: оконные функции, CTE, когортные запросы, ретеншн; PostgreSQL и ClickHouse.
3. **Алгоритмы**: LeetCode easy и около 100 medium (хэш-таблицы, два указателя, скользящее окно, префиксные суммы).
4. **Математика**: линейная алгебра, матанализ, теория вероятностей, статистика, A/B-тесты.
5. **Классическое ML**: всё от линейной регрессии до бустинга, с реализациями с нуля (логрегрессия, K-Means, ROC-AUC, градиентный спуск).
6. **Градиентный бустинг** (CatBoost/LightGBM) и feature engineering как главный рабочий инструмент.
7. **Deep Learning на PyTorch**: MLP, CNN, трансформеры и attention, дообучение (LoRA), эмбеддинги.
8. **LLM/RAG-приложение** с честной оценкой качества.
9. **Продакшен**: Docker, FastAPI, MLflow, Linux, CI, базовый мониторинг.
10. **Портфолио**: 3 проекта (см. ниже).

**Надстройка для Data Engineer** (+30–40% к объёму): Spark/PySpark, Airflow, Kafka, моделирование хранилищ (звезда, SCD, партиции), ClickHouse/Greenplum, dbt, проверки качества данных, объектные хранилища. В курсе это отдельная ветка, которую можно пройти позже.

## 4. Чем проверяется готовность (как на собеседовании)

Курс копирует реальную структуру отбора (на примере Яндекса, у других бигтехов похоже):

| Секция собеседования | Где в курсе тренируется |
|---|---|
| Онлайн-контест: 2–3 задачи на Python за 60–90 мин | Модуль 1, Модуль 5, экзамены на время |
| Алгоритмы: 2 задачи medium | Модуль 5 + ежедневное повторение |
| Теория вероятностей и статистика, A/B-тесты | Модуль 2, Модуль 10 |
| ML-теория (bias-variance, L1/L2, ROC-AUC vs PR, бустинги, деревья…) | Модуль 6 |
| ML live coding: ROC-AUC, K-Means, градиентный спуск на numpy, self-attention на PyTorch | Модули 6–8, практика «с нуля» |
| ML System Design (рекомендации, фрод, ранжирование) | Модули 12–13 |
| SQL: окна, ретеншн, self-join | Модуль 3 + повторение |

## 5. Портфолио, которое реально работает

- 2–3 end-to-end проекта, развёрнутых: Docker + FastAPI + рабочий URL, тесты, трекинг экспериментов, README с метриками и обоснованием решений.
- Одно LLM/RAG-приложение с набором для оценки качества.
- Один проект на грязных реальных данных: защита от утечки, правильная валидация, анализ ошибок.
- Один пайплайн данных (Airflow + Spark/ClickHouse) — для DE-направления.
- Kaggle-медаль и ML-кубки (Yandex Cup, ODS) — плюс, но не замена инженерным проектам. Копии Titanic/MNIST и сертификаты курсов почти ничего не дают.

## 6. Определение «курс пройден»

Курс считается пройденным, когда выполнены все условия:
- Все модули ствола и выбранной ветки сданы на экзамене не ниже 85%, без единого «слабого» концепта (каждый ≥ 80%).
- Прогноз удержания по всем концептам ≥ 85% через 30+ дней после изучения (не «сдал и забыл»).
- Сданы 3 capstone-проекта по рубрике (код, README, метрики, деплой).
- Пройден финальный «мок-собес»: контест на время + устные секции с Claude по рубрике.

**Планка — выше джуна.** Курс не обещает должность middle без опыта, но каждый курсовой проект повторяет типичную рабочую задачу джуна и middle (пайплайн данных, табличная модель с честной валидацией, A/B-кейс, RAG с оценкой, сервис с мониторингом). Выпускник приходит на работу с уже отработанными базовыми задачами — это и даёт быстрый рост внутри компании.

## 7. Честная модель сроков

Объём: около **1 790 часов** дисциплин + 6 курсовых проектов (~180 ч) ≈ **2 000 часов** (с учётом Курса 0, практик, английского и безопасности). Оценки уточняются на пилоте: методист-ревьюер считает, что реальные часы для новичка могут быть на 20–30% выше.

| Темп | Календарный срок |
|---|---|
| 8 ч в неделю | ≈ 4,8 года |
| 15 ч в неделю | ≈ 2,5 года |
| 25 ч в неделю | ≈ 1,5 года |
| 40 ч в неделю (как работа) | ≈ 1 год |

Ежедневное повторение (15–25 минут) входит в эти часы.

**Оценка независимого ревьюера (ноябрь 2026):** для новичка реальное время, скорее всего, выше плана — около 2 300–2 500 часов на дисциплины и ~300 часов на проекты, то есть **2 500–2 900 часов**. Лишнего в программе около 3 %; объём — следствие широты и принципа «сначала своими руками». Плановые часы будут уточняться по фактическому времени прохождения (платформа его измеряет).

## 8. Выходы на рынок по ходу курса

Не нужно ждать выпуска, чтобы начать откликаться:

| После | Можно претендовать на |
|---|---|
| Курса III | Стажёр или junior аналитик данных (SQL, pandas, EDA, статистика) |
| Курса IV | Стажировки ML/DS в бигтехе (Яндекс, Т-Банк, Сбер, Avito, Ozon) — отбор весной и осенью; junior DS |
| Курса V | Junior ML / AI-инженер (LLM, RAG) |
| Выпуска | Junior+ ML Engineer / Data Scientist; DE — с полной веткой Big Data |

Алгоритмы для собеседований тренируются в Тренажёре с Курса II: цель к Курсу IV — 150+ задач, еженедельный контест на время.
