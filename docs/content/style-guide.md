# Руководство по стилю учебных текстов

> Цель: весь курс читается как **одна книга одного автора** — с единым голосом, единой разметкой и единым визуальным языком, а не как подборка из разных источников.

## 1. Голос

- **Говорим с учеником на «вы», как старший коллега:** уважительно, прямо, без сюсюканья и без канцелярита.
- **Сначала зачем, потом что, потом как.** Каждая тема открывается вопросом или проблемой, которую она решает («Почему модель с точностью 99% может быть бесполезной?»).
- **Объясняем через образ, потом формализуем.** Сначала картинка или бытовой пример, затем строгое определение, затем формула, затем код.
- **Строгость не жертвуется ради простоты.** Упрощения допустимы, но помечаются: «пока будем считать, что…; в теме 6.3 уточним».
- **Длина — по необходимости.** Ключевая теория может занимать несколько экранов — это нормально. Сжатие «целой главы в пять предложений» запрещено. Скучным текст делает не длина, а монотонность — с ней боремся разметкой (раздел 3) и ритмом (раздел 2).
- **Предложения короткие, абзацы 3–6 строк.** Одна мысль — один абзац.
- **Никаких «как известно», «очевидно», «легко видеть».** Если очевидно — покажите.
- **Термин вводится один раз** — жирным, с определением; дальше он подсвечивается как глоссарный (раздел 4).
- **Связи с прошлым и будущим проговариваются явно:** «Это то же скалярное произведение из темы II.3.1.1 — только теперь векторы — это слова».

## 2. Ритм темы

Стандартная тема (30–90 минут) собирается из блоков в таком порядке. Порядок можно менять, но в каждой теме должны быть все обязательные блоки.

| Блок | Обязателен | Что это |
|---|---|---|
| Крючок | да | Вопрос, парадокс или задача, ради которой тема существует |
| Интуиция | да | Образ, пример, интерактивная визуализация |
| Строго | да | Определения, теорема или правило, формулы |
| Разбор | да | Полностью решённый пример, шаг за шагом |
| Проверь себя | да | 1–3 встроенных вопроса по ходу текста |
| Под капотом | по теме | Как это устроено внутри (код своими руками) |
| Ловушки | по теме | Типичные ошибки и заблуждения |
| В ML / в работе | да | Где это встретится дальше в курсе или на работе |
| Практика | да | Задачи в песочнице рядом с текстом |
| Итог | да | 3–5 строк: что теперь умеете |

Каждые 2–3 экрана текста — визуальная «пауза»: иллюстрация, интерактив, вопрос или выделенный блок.

## 3. Выделения и врезки

Все выделения — компоненты разметки. Ученик быстро привыкает к их смыслу, поэтому **один вид выделения — одно значение**.

| Разметка | Как выглядит | Когда использовать |
|---|---|---|
| `**жирный**` | жирный | Новый термин при первом появлении; ключевое слово абзаца — не чаще раза на абзац |
| `*курсив*` | курсив | Логическое ударение, оговорка |
| `<Mark>` | жёлтый маркер, как в бумажном учебнике | Главная мысль темы — 1–3 раза на тему |
| `<Term id="...">` | подчёркнутый пунктиром; при наведении — карточка с определением | Глоссарный термин (раздел 4) |
| `<Aside>` | заметка на полях справа от текста (на телефоне — сворачиваемая) | История, любопытный факт, ссылка на первоисточник |
| `<Tip>` | врезка с иконкой лампы | Практический совет |
| `<Pitfall>` | врезка с иконкой предупреждения | Типичная ошибка |
| `<Formula>` | формула крупно, с подписями частей при наведении | Ключевая формула темы |
| `<Figure>` | иллюстрация с подписью | Статичный график или схема |
| `<Viz>` | интерактивная визуализация | Когда ученик должен «покрутить» сам |
| `<Check>` | встроенный вопрос | Проверь себя |
| `<Sandbox>` | песочница рядом с текстом | Практика |
| `<Source>` | строка «Соответствует: …» в конце | Ссылка на канонический курс и главу |

**Формула с подписями.** Для ключевых формул каждая часть подписывается: наводите на $\sigma$ — видите «сигмоида: сжимает любое число в интервал (0; 1)». Это заменяет абзац «где … — это …, … — это …».

## 4. Глоссарий и подсветка терминов

- Глоссарий — общий файл `content/glossary.yaml`. Термин: `id`, название, короткое определение (1–2 предложения своими словами), тема, где введён, синонимы и английское название.
- В тексте термин размечается `<Term id="cross-entropy">кросс-энтропия</Term>` — или автоматически: платформа находит в тексте термины и синонимы из глоссария.
- **Где подсвечивается.** От темы, где термин введён, до конца её **дисциплины** (настройка ученика: тема / раздел / дисциплина / курс / всегда / никогда). Позже термин остаётся ссылкой, но без жёлтого фона, чтобы текст не пестрел.
- **Что показывает карточка:** определение, мини-пример или формула, «введено в теме II.3.2.1», кнопка «В шпаргалку».
- Термин, по которому у ученика низкая прочность в повторении, подсвечивается снова — независимо от настройки.

## 5. Иллюстрации

- **Компактные и функциональные.** Иллюстрация показывает одну идею. Никаких «декоративных» картинок.
- **Единый стиль:** тонкие линии цвета текста, один акцентный цвет для главного, подписи прямо на рисунке (не в легенде), шрифт интерфейса.
- **Математика:** графики с подписанными осями и аннотациями («здесь производная равна нулю»), стрелками и пунктирами.
- **Схемы процессов:** слева направо, не больше 7 элементов.
- **Как делаются:** графики — из данных компонентами `<Figure>` (SVG по токенам темы, работают в светлой и тёмной теме); схемы — mermaid или SVG; анимации — заранее отрендеренное видео (Manim) только если без движения идею не понять.
- Каждая иллюстрация имеет подпись из одного предложения и альтернативный текст.

## 6. Код в тексте

- Примеры кода короткие (до 15 строк), запускаемые, с выводом под ними.
- Имена переменных — осмысленные, на английском; комментарии — на русском.
- Код, который ученик должен будет написать сам в практике, в теории не приводится целиком.

## 7. Проверка темы перед публикацией

- Все обязательные блоки на месте (валидатор проверяет).
- Каждый новый термин есть в глоссарии.
- Каждая иллюстрация читается в обеих темах.
- Нет ссылок «вперёд» на непройденное без пометки «узнаем в теме …».
- Тему прочитал ревьюер-«ученик» (субагент с профилем новичка) и отметил места, где непонятно.
