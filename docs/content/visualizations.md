# Визуализации и тренажёры по всему курсу

> Правило: **у каждой дисциплины есть хотя бы одна «фирменная» интерактивная визуализация**, в которой ученик своими руками видит главную идею. Плюс тренажёр, где эта идея отрабатывается.
> Визуализации — переиспользуемые компоненты (`<Viz kind="...">`). Один компонент служит многим темам, поэтому список ниже — это одновременно план разработки библиотеки визуализаций.

Обозначения: **Viz** — интерактивная визуализация в тексте темы; **Тренажёр** — песочница или упражнение с автопроверкой; ★ — фирменная визуализация дисциплины.

## Курс I. Фундамент

| Дисциплина | Viz | Тренажёр |
|---|---|---|
| Вводная | ★ Демо «нарисуй цифру — модель угадает» с живыми вероятностями; поиск по смыслу на 50 фразах | — |

| Git и GitHub | ★ Живой граф коммитов: каждая команда двигает HEAD и ветки; три зоны — рабочая папка → индекс → репозиторий | Песочница Git с целевой картинкой графа («приведи репозиторий к такому виду»), конфликты слияния, финал — реальный push в свой GitHub |
| Python I | ★ Пошаговое выполнение кода: переменные, объекты и стрелки-ссылки (почему `[[0]*2]*2` ломается); стек вызовов для рекурсии | Редактор с тестами; задачи Парсонса (собрать код из строк); «предскажи вывод» |

## Курс II. Математика и алгоритмы

| Дисциплина | Viz | Тренажёр |
|---|---|---|
| Python II | Диаграмма классов из вашего кода; генератор как «ленивая лента» значений | Тесты, mypy и ruff прямо в песочнице; задачи «найди запах в коде» |
| Алгоритмы I | ★ Анимация алгоритмов по шагам: сортировки, бинарный поиск, два указателя, окно; график «время от n» для O(n), O(n log n), O(n²) на вашем же коде | Контест-режим с таймером и скрытыми тестами на время; замер сложности решения |
| Линейная алгебра | ★ Плоскость, которую деформирует матрица (сетка, базисные векторы, площадь = определитель); собственные направления, которые не поворачиваются; SVD как поворот → растяжение → поворот; проекция точки на прямую | Матричный калькулятор «руками» (ученик делает шаги метода Гаусса, система проверяет каждый шаг); свой класс Matrix против NumPy |
| Матанализ | ★ Секущая превращается в касательную; поверхность функции двух переменных с градиентом-стрелкой; шарик градиентного спуска с регулируемым шагом (слишком большой — расходится); цепное правило как граф вычислений | Символьная проверка производных; численная проверка градиента своего кода |
| Теория вероятностей | ★ Симулятор: бросайте монеты и кости тысячами, гистограмма сходится к распределению; ЦПТ вживую — сумма любых величин становится «колоколом»; дерево Байеса для «теста на болезнь» | Монте-Карло задачи: ответ проверяется сравнением с аналитическим; генераторы задач на Байеса |
| Статистика | ★ Доверительные интервалы: 100 выборок, видно, какие интервалы «промахнулись»; p-value как площадь хвоста; мощность теста от размера выборки | Свой бутстрап и t-тест против SciPy; «интерпретируй результат» — проверяет Claude |

## Общие компоненты, из которых всё собирается

Чтобы не писать 60 уникальных визуализаций, библиотека строится из ~15 базовых блоков:

1. **Plane2D** — координатная плоскость: точки, векторы, функции, области, перетаскивание (линал, матанализ, ML-модели)
2. **Surface3D** — поверхность функции двух переменных с траекториями (оптимизация)
3. **TableViz** — таблицы со связями и подсветкой строк (SQL, pandas, рекомендации)
4. **GraphViz** — графы: коммиты, вычислительные графы, алгоритмы на графах, нейросети, агенты
5. **StepPlayer** — пошаговый проигрыватель с кнопками «вперёд/назад» для любых алгоритмов
6. **Histogram/Sim** — симуляции и распределения
7. **MemoryViz** — объекты и ссылки, память массивов
8. **Heatmap** — матрицы, внимание, пропуски, корреляции
9. **Embedding2D** — облака точек с подписями (эмбеддинги, PCA, кластеры, RAG)
10. **Pipeline** — блоки слева направо (данные, RAG, системы)
11. **Terminal/FS** — дерево файлов и вывод команд
12. **Formula** — формулы с подписями частей
13. **Slider/Control** — общие элементы управления
14. **Compare** — «до/после», «ваш код/эталон»
15. **Canvas** — рукописный ввод

Каждая визуализация темы — это настройка одного-двух блоков, а не новый код.
