# 02. Программа курса

> Общий объём: около **1 100–1 250 часов** чистого времени. При 12–15 ч в неделю это примерно 18–24 месяца.
> Модули идут строго по порядку, но математика (М2) идёт параллельно с Python и SQL, чтобы не было «стены» из чистой теории.
> Источники по каждому модулю — в [05-sources.md](05-sources.md).

## Карта

```
СТВОЛ (обязателен для всех)
 M0 Инструменты ─► M1 Python ─► M3 SQL ─► M4 Анализ данных ─► M6 Классическое ML ─► M7 Deep Learning ─► M8 NLP/Трансформеры
                    ║                                          ▲
                    ╚═► M2 Математика (параллельно) ═══════════╝
                    ║
                    ╚═► M5 Алгоритмы (параллельно, по 2–3 задачи в неделю до конца курса)

ВЕТКИ (после M8)
 ML Engineer:  M9 LLM-инженерия ─► M12 MLOps ─► M11-lite Big Data
 Data Science: M10 Продуктовая статистика ─► M11-lite Big Data ─► M12-lite MLOps
 Data Engineer: M11 Big Data (полный) ─► M12 MLOps
 Опционально:   M8b Компьютерное зрение

ФИНАЛ
 M13 Capstone-проекты и подготовка к собеседованиям
```

Рекомендация для этого курса: пройти **ствол + обе ветки MLE и DS**, Big Data — в «lite»-объёме, полный DE — позже, если понадобится.

## Модули

Формат: **предпосылки · часы** → темы уроков → что ученик умеет после модуля → как проверяется.

### M0. Инструменты разработчика · 20 ч
Предпосылки: нет.
- Терминал: файловая система, навигация, пайпы, права, переменные окружения
- Git: init/add/commit, ветки, merge, rebase, конфликты, remote, pull request, GitHub flow
- Окружения: uv/pip, venv, зачем изоляция
- VS Code и Jupyter
- Как читать ошибки и трейсбеки, как искать ответ
- После: клонирует, ветвит, коммитит, открывает PR, запускает скрипт в изолированном окружении.
- Проверка: песочница Git (проверка состояния репозитория), песочница терминала (проверка файловой системы).

### M1. Python · 70 ч
Предпосылки: M0.
- Типы, условия, циклы, функции
- Списки, словари, множества, comprehensions; изменяемость и ссылки (классическая ловушка `[[0]*2]*2`)
- Строки, файлы, JSON/CSV, pathlib
- Исключения
- Классы, dataclasses, наследование, магические методы
- Модули и пакеты
- Итераторы, генераторы, декораторы, контекстные менеджеры
- Типизация, ruff, mypy
- Тестирование: pytest, фикстуры, property-based тесты
- Стандартная библиотека: collections, itertools, functools, re
- Сложность алгоритмов (O-большое) на практике
- После: пишет и тестирует программы на 100–300 строк, читает чужой код.
- Проверка: скрытые pytest-тесты, ограничение по времени, статические проверки.

### M2. Математика · 190 ч (параллельно с M1, M3, M4)
Предпосылки: школьная алгебра. Каждый подмодуль заканчивается практикой «руками» и «в NumPy».
- **M2a. Алгебра и функции (15 ч)**: функции и графики, степени и логарифмы, суммы (Σ), неравенства
- **M2b. Линейная алгебра (50 ч)**: векторы, скалярное произведение, матрицы как преобразования, умножение матриц, системы уравнений и метод Гаусса, ранг, определитель, обратная матрица, собственные векторы, SVD, связь с PCA
- **M2c. Матанализ (45 ч)**: пределы, производная, правило цепочки, частные производные, градиент, якобиан, ряд Тейлора, градиентный спуск, выпуклость
- **M2d. Теория вероятностей (45 ч)**: комбинаторика, условная вероятность, Байес, случайные величины, распределения, матожидание и дисперсия, ЗБЧ и ЦПТ, MLE/MAP, энтропия и KL-дивергенция
- **M2e. Статистика (35 ч)**: описательная статистика, выборки, доверительные интервалы, проверка гипотез, p-value, ошибки I и II рода, мощность, бутстрап, множественные сравнения
- После: берёт производную функции потерь, считает матрицы руками и в NumPy, читает и строит статистический тест.
- Проверка: песочница математики (символьная и численная проверка ответа), задачи в NumPy с тестами, устные объяснения с проверкой Claude.

### M3. SQL и базы данных (PostgreSQL) · 45 ч
Предпосылки: M0.
- SELECT, WHERE, ORDER BY, LIMIT
- Агрегаты, GROUP BY, HAVING, NULL и его ловушки
- JOIN всех видов, self-join
- Подзапросы и CTE, рекурсивные CTE
- Оконные функции: ранги, скользящие суммы, LAG/LEAD
- Аналитические кейсы: ретеншн, когорты, воронки, DAU/MAU
- DDL, ключи, ограничения, нормализация
- Индексы и EXPLAIN
- Транзакции и ACID
- Python + Postgres (psycopg, SQLAlchemy)
- Обзор ClickHouse: чем колоночная БД отличается
- После: отвечает на аналитические вопросы по многотабличной схеме с оконными функциями.
- Проверка: сравнение результата запроса с эталоном на свежей базе (PGlite в браузере).

### M4. Анализ данных · 60 ч
Предпосылки: M1, M2e (основы), M3.
- NumPy: массивы, broadcasting, векторизация вместо циклов
- pandas: индексация, groupby, merge, pivot, временные ряды
- Очистка данных: пропуски, выбросы, типы, дубликаты
- Визуализация: matplotlib, seaborn, plotly; какой график для какой задачи
- EDA (разведочный анализ) от начала до выводов
- Воспроизводимость ноутбуков, валидация данных
- После: чистит грязный датасет и пишет EDA-отчёт с выводами.
- Проверка: тесты на возвращаемый DataFrame; отчёт EDA — рубрика Claude.

### M5. Алгоритмы и структуры данных · 60 ч (растянуты на весь курс)
Предпосылки: M1.
- Массивы и строки, хэш-таблицы, два указателя, скользящее окно, префиксные суммы
- Стек, очередь, связный список
- Бинарный поиск
- Сортировки
- Деревья и графы: BFS, DFS
- Куча
- Динамическое программирование (база)
- После: решает easy стабильно и medium в пределах 30–40 минут.
- Проверка: скрытые тесты + лимит времени + замер времени решения.

### M6. Классическое машинное обучение · 120 ч
Предпосылки: M2b–e, M4.
- Постановка задачи, train/val/test, кросс-валидация
- Линейная регрессия (с нуля и в sklearn), функции потерь
- Логистическая регрессия, вывод градиента
- Регуляризация L1/L2
- kNN, наивный Байес
- Деревья решений (Gini, энтропия)
- Случайный лес, бэггинг
- Градиентный бустинг: идея, XGBoost/LightGBM/CatBoost
- SVM и ядра
- Метрики: accuracy, precision/recall, ROC-AUC, PR-AUC, RMSE, MAE; выбор метрики
- Bias-variance, переобучение
- Feature engineering, кодирование категорий
- Дисбаланс классов, калибровка
- Утечки данных
- Кластеризация (K-Means с нуля), PCA
- Интерпретация (SHAP)
- Пайплайны scikit-learn
- После: строит, валидирует и тюнит табличную модель без утечек и объясняет выбор метрики.
- Проверка: модель проходит порог качества на скрытой выборке; реализации «с нуля» сверяются с sklearn; устная ML-теория — Claude.
- Capstone: Titanic → House Prices → Spaceship Titanic.

## Как делится каждый модуль

```
Модуль
 ├─ Пре-тест (без оценки) — что уже знаешь, можно пропустить уроки
 ├─ Урок 1..N
 │   ├─ Теория простым языком + визуализация + примеры
 │   ├─ Проверь себя (2–4 вопроса прямо в тексте)
 │   ├─ Квиз урока (70–80% новое, 20–30% повторение)
 │   └─ Практика (задачи с автопроверкой, подсказки по уровню)
 ├─ Чекпоинты каждые 3–4 урока (устный ответ, проверяет Claude)
 └─ Экзамен модуля (30–40% вопросов из прошлых модулей, порог 85%)
```
