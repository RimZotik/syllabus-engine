# Дизайн-система

> Живой образец — `design/mockup/index.html`. Этот документ фиксирует правила, чтобы новые экраны выглядели частью одной платформы.

## 1. Принципы

- **Минимализм через типографику и пространство, а не через рамки.** Группы разделяются отступами и тонкими линиями; карточки с рамкой — только для объектов, которые действительно «отдельны» (песочница рядом с текстом).
- **Внимание — только на главное.** На каждом экране одна основная кнопка; второстепенные действия — текстовые.
- **У каждого типа страницы своё лицо при общей системе** (раздел 4).
- **Обе темы — светлая и тёмная — равноправны.** Все цвета — токены.
- **Без эмодзи.** Иконки — lucide (контурные, скруглённые, толщина 1.75), по центру относительно текста.

## 2. Токены

**Палитра «северное сияние»:** белая бумага для чтения, текст почти чёрный с зелёным оттенком, два акцента — **нефритовый зелёный** и **фиолетовый**. У каждого своя роль, и они не смешиваются случайно.

| Группа | Токены (светлая тема) | Роль |
|---|---|---|
| Бумага | `--bg` #ffffff, `--surface` #ffffff, `--tint` #f5f8f6, `--fill` #f1f5f3 | фон страниц; лёгкая подложка панелей и полей ввода |
| Текст | `--ink` #12201b, `--ink-2` #4a5a54, `--ink-3` #8b9a94 | основной, вторичный, подписи |
| Линии | `--line` #e7edea, `--line-2` #d6dfdb | разделители (вместо рамок) |
| **Зелёный** | `--accent` #0d8f6c, `--accent-2` #13b386, `--accent-soft` | **действие**: кнопки, активное состояние, прогресс, ссылки |
| **Фиолетовый** | `--violet` #7457e8, `--violet-soft` | **знание**: термины глоссария, повторение, открываемые библиотеки, Claude |
| Градиент зелёный → фиолетовый | — | только «фирменные» моменты: заголовок главной, знак преподавателя, линия активного пункта меню |
| Смысловые | `--ok`, `--warn`, `--bad` и `-soft` | только статусы проверок |
| Маркер | `--mark` #fff0a8 | жёлтое выделение главной мысли в тексте |
| Тени | `--sh1` (цветная «желейная» тень кнопок), `--sh2` (мягкая для второстепенных), `--sh3` (поднятые панели — песочница) | |

Тёмная тема — «ночное небо»: фон #0a1311, акценты светлее (#2fd19f, #a28bff).

## 3. Шрифты

Тёплые скруглённые гротески без засечек: мягкие формы меньше утомляют глаза на длинном тексте.

| Роль | Шрифт | Где |
|---|---|---|
| Заголовки и крупные числа | **Rubik** | заголовки, номера курсов, метрики |
| Интерфейс и чтение теории | **Nunito** | весь текст; в теме — 18px, межстрочный 1.75, ширина строки ≈ 68 знаков |
| Код и данные | **JetBrains Mono** | код, таблицы данных |

Все — с полной кириллицей. Шкала размеров: 12 / 13 / 16 / 18 / 22 / 28 / 34 / 44 / 76.

## 4. Лица страниц

| Страница | Характер | Приёмы |
|---|---|---|
| **Главная** | Презентация курса | Крупная типографика, живая карта функции потерь с градиентным спуском в шапке, длинная прокрутка блоков: для кого → что будете уметь → как устроено → программа → проекты → преподаватель → вопросы |
| **Обучение · план** | Учебная ведомость | Строки дисциплин с прогрессом, курсы как главы, одна кнопка «Продолжить» |
| **Обучение · тема** | Книга | Крупный шрифт для чтения, колонка ≈ 68 знаков, заметки на полях, песочница справа; режимы «Тема / Контрольная / Экзамен» переключаются на месте без ухода со страницы |
| **Контрольная** | Экзаменационный лист | Нумерованные вопросы, таймер, никаких отвлечений |
| **Экзамен** | Диалог | Чат с преподавателем и карта концептов билета |
| **Тренажёр** | Инструмент | Компактный список режимов, справа — календарь рубежей |
| **Зачётка** | Документ | Таблица оценок как в зачётной книжке, сводные показатели, профиль обучения |

## 5. Кнопки

- **Основная:** без рамки; вертикальный градиент зелёного (`--accent-2` → `--accent`), цветная мягкая тень снизу (`--sh1`) — «желейный» объём; при наведении приподнимается на 1px и становится чуть ярче, при нажатии «вдавливается».
- **Второстепенная:** без рамки, белая с мягкой нейтральной тенью (`--sh2`).
- **Текстовая:** только цвет акцента и стрелка.
- **Переключатели режимов:** сегменты на общей подложке, выбранный — «приподнят».
- Высота 42px (основная), 34px (компактная). Иконка слева по центру текста.

## 6. Компоненты чтения

`Mark` (жёлтый маркер) · `Term` (пунктир + карточка определения при наведении) · `Aside` (заметка на полях) · `Tip` / `Pitfall` (врезки с иконкой и вертикальной линией слева, иконка по центру блока) · `Formula` (подписи частей при наведении) · `Figure` (SVG по токенам) · `Viz` · `Check` · `Sandbox` · `Source`.

Правила их использования для авторов — в [style-guide.md](../content/style-guide.md). Каждый компонент — отдельный React-компонент в `apps/web/src/content/`, подключённый в MDX один раз; новые компоненты добавляются туда же и документируются здесь.

## 7. Навигация

- Верхняя панель на всю ширину: логотип · Обучение · Тренажёр · Зачётка · справа статус Claude и лимиты, тема, профиль.
- Активный пункт — линия снизу, угасающая вправо.
- Внутри темы — оглавление раздела слева с вертикальной линией у текущей темы.

## 8. Адаптивность

- ≥ 1100px: тема в три колонки (оглавление · текст · песочница).
- 760–1100px: оглавление скрыто, песочница под текстом.
- < 760px: одна колонка, отступы 16px, таблицы прокручиваются внутри своих блоков; верхняя панель без логотипа-текста и лимитов.
