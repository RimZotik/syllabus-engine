# Готовое приложение одного обучения (для тех, кто не может запускать разработку)

Команда `npm run bundle -- <id>` собирает из `courses/<id>/` один файл `bundles/<id>/<id>.exe` и архив `bundles/<id>.zip`. Внутри — сервер платформы, готовые страницы и **только это** обучение: другие пакеты и данные разработчика в сборку не попадают.

## Что получает человек

- Двойной щелчок по `.exe` — обучение открывается в браузере, который выбран у пользователя по умолчанию (Chrome, Edge, Firefox…). Повторный запуск, пока приложение работает, просто снова открывает обучение. У каждого обучения свой постоянный адрес (`127.0.0.1:47xxx`), поэтому браузер помнит настройки страницы между запусками.
- Приложение выключается само через 5 минут после того, как закрыта последняя вкладка обучения: открытая страница раз в 30–60 секунд обращается к серверу (вкладка в фоне — не реже раза в минуту). Если компьютер уходил в сон, отсчёт начинается заново.
- Ничего не нужно устанавливать: ни Python, ни Node.
- Прогресс хранится у него: `%LOCALAPPDATA%\SyllabusEngine` (база, журнал `logs\desktop.log`).
- **Преподаватель-ИИ** включается сам, если на компьютере установлен и подключён Claude Code — та же проверка, что в разработке. Без него обучение проходится полностью, кроме проверки развёрнутых ответов (платформа так и пишет в окне Claude).

## Как устроено

1. Во временной папке собирается копия `apps/web` и одной папки обучения (без `docs/` и `dev/` — это рабочие материалы авторов), `node_modules` подключается ссылкой.
2. Vite собирает страницы. Python в браузере (Pyodide, десятки МБ) кладётся, только если в обучении есть задачи `python-browser`.
3. PyInstaller замораживает сервер (`apps/server/syllabus_server/desktop.py`) со страницами и обучением внутри в один `.exe`.
4. Сервер в сборке сам отдаёт страницы (`SYLLABUS_WEB_DIST`), обучение берёт из себя (`SYLLABUS_CONTENT_ROOT`).

Проверка сборки без окна на экране: `SYLLABUS_HEADLESS_PORT=8791 SYLLABUS_DATA_DIR=<временная папка> <id>.exe` — приложение только поднимает сервер на этом порту.

## Ограничения и дальше

- Собирается только под Windows на Windows (PyInstaller не собирает под другие системы). Сборку под macOS — через CI.
- Файл не подписан: Windows SmartScreen при первом запуске может спросить «Запустить всё равно?». Подпись кода — когда появятся настоящие пользователи.
- Обновление обучения — новая сборка; прогресс сохраняется, потому что темы адресуются по id.
- При желании этот же `.exe` можно обернуть в Tauri (своя иконка, установщик) — сервер станет sidecar-процессом, остальное не меняется.
- Сайт для многих учеников — отдельный путь, см. [hosting-roadmap.md](hosting-roadmap.md).
