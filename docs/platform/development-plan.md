# 06. План разработки

> Порядок по правилу «сначала данные»: хранилище и формат контента → логика (проверка, повторение) → интерфейс → Claude.
> Контент производится параллельно с платформой и держится на 1–2 модуля впереди ученика.

## Этап 0. Концепция — готово
- Исследование рынка, программы, методики и технологий
- Документы `docs/`, кликабельный макет `design/mockup/index.html`

## Этап 0.5. Полная программа — готово
- `content/forge-ml/program.yaml`: все курсы до уровня тем; скрипт `tools/program/build.py` проверяет порядок и генерирует `content/forge-ml/docs/curriculum.md`
- Документ о преподавателе Claude (`docs/07`)
- Независимое ревью программы и макета (ученики, методист, работодатели, дизайнер)

## Этап 1. Скелет платформы (MVP: можно пройти первый урок)
- Монорепозиторий: `apps/server` (FastAPI + SQLite + Alembic), `apps/web` (Vite + React + TS), запуск `uv run forge start`
- Формат контента и валидатор (`module.yaml`, `lesson.mdx`, `exercise.yaml`, `skills.yaml`)
- Читалка уроков: MDX, KaTeX, компонент визуализации
- Раннер `python-browser` (Pyodide в воркере) + CodeMirror + скрытые тесты + таймаут
- Прогресс и попытки в базе
- Пилотный контент: Курс I — «Компьютер и терминал» целиком и первый раздел «Git локально»
- Критерий готовности: на чистой машине `git clone` → одна команда → урок пройден, прогресс сохранён

## Этап 2. Методика в коде
- Квизы всех типов (выбор, мультивыбор, Парсонс, предскажи вывод, численный ответ)
- FSRS по концептам, дневная очередь повторения, доли повторения в квизах и экзаменах
- Экзамены модулей с порогами, пересдачей через 24 ч и вариантами
- Лестница подсказок, дружелюбные ошибки (Ruff + свой словарь ошибок на русском)
- Заметки, шпаргалки, «предложить улучшение»
- Телеметрия редактора и профиль ученика
- Тесты на граничные случаи расписания: переход через полночь и часовые пояса, долгий перерыв (режим отпуска), повторная сдача, пустой пул вариантов, одновременная работа в двух вкладках

## Этап 3. Остальные песочницы
- `sql` (PGlite) со сравнением результатов
- `git-browser` (isomorphic-git + xterm.js) и `shell`-симулятор
- `math` (MathLive + Compute Engine + SymPy)

## Этап 4. Claude
- MCP-сервер внутри FastAPI, токен, команда подключения
- Проверяющий для устных ответов (`claude -p` с JSON-схемой), рубрики, очередь, оспаривание
- Кнопка «Позвать Claude» и авто-триггеры
- Панель лимитов через statusline-скрипт
- Еженедельный комментарий наставника

## Этап 5. Тяжёлые модули
- Раннер `python-kernel` (Jupyter-ядро), отдельная установка PyTorch/Spark
- Kaggle API, режим «запусти в Colab/Kaggle и сдай метрики»
- `git-real` и настоящий терминал

## Этап 6. Публикация
- README для всех, скриншоты, лицензии, CONTRIBUTING (как писать уроки)
- CI: валидатор контента, тесты сервера и фронтенда, проверка эталонных решений против своих тестов
- Docker-режим запуска
- Перепроверка правил использования подписки Claude

## Производство контента (параллельно)
- Один урок = теория + 2–4 «проверь себя» + квиз (5+ вариантов на концепт) + 3–6 задач с тестами + рубрики устных вопросов.
- Пишет Claude по шаблону урока, исходя из источников; каждое эталонное решение автоматически прогоняется против своих тестов в CI.
- Заметки ученика с пометкой «улучшение» разбираются после каждого модуля.
