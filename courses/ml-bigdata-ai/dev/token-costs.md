## Оценка на будущее

Готово тем: **57** из 421 в программе. Содержательные этапы (всё, кроме платформы и обсуждения) — 156.4 млн взвешенных токенов, то есть **≈ 2.7 млн на тему** (с тестами, задачами и всеми кругами проверки).

| Этап | На одну тему, млн |
|---|---:|
| Проектирование: источники, план, деревья предпосылок | 0.3 |
| Теория: написание | 0.9 |
| Теория: проверка (методист, ученик, редактор) | 0.4 |
| Определения, факты и цитаты: фактчек | 0.1 |
| Тесты: написание и экзаменатор | 0.9 |
| Задачи песочницы: написание и проверка | 0.2 |

Оставшиеся 364 тем по той же цене — **≈ 998.7 млн** взвешенных токенов. Это грубая оценка: темы с программированием дороже вводных (больше задач песочницы), а платформа и обсуждение сюда не входят — для нового курса на готовой платформе они заметно меньше.

## Как вести учёт дальше

Описание каждого субагента начинается с этапа: `design:`, `theory:`, `theory-review:`, `facts:`, `tests:`, `tasks:`, `platform:`, `teaching-audit:` — например `theory-review: prog1.functions`. Тогда отчёт не угадывает этап по словам. Работа основного диалога делится по тому, какие файлы он менял.
