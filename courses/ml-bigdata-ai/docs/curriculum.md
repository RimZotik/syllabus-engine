## Как устроено

- **Предмет** — сквозная линия (Введение в специальность, Инфраструктура, Контроль версий…). У предмета есть уровни: I, II, III…
- **Дисциплина** — один уровень предмета на конкретном курсе (например, «Программирование II»). Уровень растёт, когда в предмете появляются новые темы; повторение уровень не повышает.
- Внутри курса дисциплины идут строго друг за другом, без чередования.
- Рубежи: курс — переводной экзамен (письменная часть + устная защита у Claude) + курсовой проект; дисциплина — экзамен по дисциплине (практика + устный опрос); раздел — контрольная (смешанные вопросы по всем темам раздела); тема — встроенные проверки и практика темы.
- Дополнительно: в середине каждого курса, начиная со II, — проверка остаточных знаний по всем прошлым курсам.
- Библиотека «открывается» только после того, как её идея реализована своими руками.
