## Пять имён — это уже неудобно

Нужно хранить температуру за пять дней. С тем, что вы знаете, получится так: `t1 = 12`, `t2 = 15`, `t3 = 9`, `t4 = -2`, `t5 = 7`. А если дней 30? А если их число становится известно только во время работы программы? Заводить имя на каждое значение нельзя — нужно одно имя на всю последовательность.

```python
temps = [12, 15, 9, -2, 7]
print(temps)
print(type(temps))
print(len(temps))
```

```
[12, 15, 9, -2, 7]
<class 'list'>
5
```

<Theorem kind="definition" title="Список"
  formal="Список — составной тип данных, который группирует другие значения. Записывается как перечень значений (элементов) через запятую в квадратных скобках. Список может содержать элементы разных типов, но обычно все элементы одного типа."
  source="Python Tutorial, 3.1.3 «Lists» (пересказ)">

<Term id="list">Список</Term> (тип `list`) — одно значение, составленное по порядку из других значений, его элементов. Имя `temps` указывает на один список, а уже в нём — пять чисел. Порядок элементов сохраняется: первым всегда будет `12`.

</Theorem>

Элементы могут быть любыми: числа, строки, логические значения, даже вперемешку — `["Аня", 20, True]` допустимо. Но на практике список почти всегда однородный: список температур, список имён. Так его проще обрабатывать.

Пустой список записывается как `[]`, его длина — `0`. Вы уже знаете из темы об условиях, что пустой список в условии считается ложью, а непустой — истиной: `if temps:` читается «если в списке что-то есть».

Список уже встречался вам, хоть и мельком: метод строк `split()` возвращает именно список.

```python
parts = "3 15 7".split()
print(parts)
```

```
['3', '15', '7']
```

Кавычки в выводе подсказывают: элементы — строки, а не числа. `parts[0] + parts[1]` даст `"315"`, а чтобы сложить числа, каждую часть сначала превращают в число: `int(parts[0]) + int(parts[1])` даёт `18`. Как превратить все части сразу, узнаете в теме о цикле `for`.

</Page>

## Всё как у строк

Элементы списка нумеруются так же, как символы строки: индекс первого — 0, последнего — `len(temps) - 1`, или короче `-1`.

```python
temps = [12, 15, 9, -2, 7]
print(temps[0], temps[1], temps[-1])
```

```
12 15 7
```

Выход за границу — та же ошибка, что у строк. Вот полное сообщение для программы `weather.py`, которая просит `temps[5]` у списка из пяти элементов:

```
Traceback (most recent call last):
  File "C:\work\weather.py", line 2, in <module>
    print(temps[5])
          ~~~~~^^^
IndexError: list index out of range
```

Читаем, как учились в теме об ошибках, снизу вверх: последняя строка — тип и текст ошибки, «индекс списка вне диапазона»; над ней — файл и номер строки кода, сама строка кода и значки `^^^` под индексом `[5]`. Индексы этого списка — от 0 до 4, значит, виноват индекс. И та же ловушка, что у строк: «первый» элемент — `temps[0]`, а `temps[1]` — уже второй.

## А вот и отличие: элемент можно заменить

Строку изменить нельзя — вы видели `TypeError: 'str' object does not support item assignment`. Со списком это работает:

```python
temps = [12, 15, 9, -2, 7]
temps[3] = 0
print(temps)
```

```
[12, 15, 9, 0, 7]
```

Запись `temps[3] = 0` — присваивание, но слева не имя, а место в списке. Правило прежнее: сначала вычисляется правая часть, потом четвёртый элемент списка начинает указывать на результат. Сам список при этом тот же самый — поменялось только его содержимое.

Возможность менять список на месте очень удобна, но у неё есть оборотная сторона. Если два имени указывают на один список, изменение «через одно имя» видно и через другое. Это главная ловушка списков, ей посвящена отдельная тема «Изменяемые и неизменяемые значения» в разделе «Коллекции». Пока работайте так, чтобы на каждый список указывало одно имя.

## Добавить в конец

Часто список заранее пуст и наполняется по ходу программы. Для этого есть метод `append` — «дописать в конец»:

```python
names = []
names.append("Аня")
names.append("Борис")
print(names, len(names))
```

```
['Аня', 'Борис'] 2
```

`append` меняет сам список: после вызова в нём на один элемент больше. Теперь соединим это с циклом `while` из прошлой темы. Программа читает список покупок, пока не будет введена пустая строка:

<Trace>

```python
shopping = []
while True:
    item = input()
    if item == "":
        break
    shopping.append(item)
print(len(shopping), shopping)
```

```input
молоко
хлеб
сыр

```

</Trace>

Ввод: три покупки, а последняя строка ввода пустая. Пройдите программу по шагам и следите за списком справа: после каждого `append` в нём появляется новый элемент, а имя `shopping` всё время указывает на один и тот же список.

Предскажите, что выведет программа, если первая же строка ввода пустая, потом сверьтесь с ответом под ловушкой ниже.

<Callout kind="warning" title="Ловушка: names = names.append(...)">
Методы строк возвращают новую строку, и результат нужно привязать к имени: `s = s.upper()`. С `append` наоборот: он меняет сам список, а возвращает особое значение `None` — «ничего». Строка кода `names = names.append("Вера")` допишет «Веру», а потом привяжет имя `names` к `None` — и список будет потерян: `print(names)` выведет `None`. Пишите просто `names.append("Вера")`. Почему одни функции возвращают результат, а другие — `None`, разберём в разделе «Функции».
</Callout>

Ответ к вопросу выше: при пустой первой строке ввода `break` сработает на первой же итерации, `append` не выполнится ни разу, и программа выведет `0 []`.

</Page>

## Оператор in

Тот же оператор `in`, что проверял подстроку, для списка проверяет, есть ли значение среди элементов:

```python
names = ["Аня", "Борис", "Вера"]
print("Борис" in names)
print("борис" in names)
print("Глеб" not in names)
```

```
True
False
True
```

Элемент должен совпасть **целиком**: `"бор" in names` даст `False`, хотя `"бор"` входит в строку `"Борис"`. И регистр важен, как и у строк. Запись `not in` читается «нет в списке».

С `in` короче записывается проверка «одно из нескольких значений»: вместо `x == 1 or x == 2 or x == 3` — `x in [1, 2, 3]`.

## Как вывести список красиво

`print(temps)` показывает список со скобками и запятыми — как его записывают в коде. Для человека чаще нужно иначе:

```python
temps = [12, 15, 9, -2, 7]
print(*temps)
names = ["Аня", "Борис", "Вера"]
print(", ".join(names))
```

```
12 15 9 -2 7
Аня, Борис, Вера
```

- Звёздочка в `print(*temps)` раскладывает список на отдельные значения — как будто вы написали `print(12, 15, 9, -2, 7)`. Значения выводятся через пробел.
- Метод строк `join` склеивает элементы списка, вставляя между ними строку, у которой его вызвали: здесь `", "`. Работает только для списка строк: `" ".join(temps)` упадёт с `TypeError: sequence item 0: expected str instance, int found`.

## Пока что — через while

Как напечатать каждую температуру на отдельной строке вывода? С тем, что уже есть, — циклом `while` по индексам от 0 до `len(temps) - 1`:

<Trace>

```python
temps = [12, 15, 9]
i = 0
while i < len(temps):
    print(temps[i])
    i += 1
```

</Trace>

Это работает, но в коде много мест для ошибки: начать с 0, а не с 1; написать `<`, а не `<=` (иначе `IndexError` на последнем шаге); не забыть `i += 1` (иначе бесконечный цикл). Перебирать элементы по одному приходится постоянно, поэтому в Python для этого есть отдельный цикл — `for`. Он и есть следующая тема.
