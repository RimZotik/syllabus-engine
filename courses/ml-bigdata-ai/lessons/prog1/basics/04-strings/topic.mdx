## Что такое строка

С текстом вы работаете с самой первой программы: `"Привет, мир!"`, всё, что вернул `input()`. Теперь заглянем внутрь.

<Theorem kind="definition" title="Строка"
  formal="Текстовые данные в Python представлены объектами str — строками. Строки — неизменяемые последовательности кодовых точек Юникода."
  source="Документация Python, Built-in Types: «Text Sequence Type — str»">

<Term id="string">Строка</Term> — это текст, а точнее последовательность символов, стоящих в определённом порядке. Слово «неизменяемые» из определения разберём на следующей странице. «Кодовые точки Юникода» — номера символов в общей для всего мира таблице символов; подробнее о ней — в теме о файлах и кодировках раздела «Текст и файлы».

</Theorem>

Строку записывают в одинарных или двойных кавычках — разницы нет. Удобно, когда внутри текста нужны кавычки другого вида: `"It's"` или `'Он сказал: "Привет"'`. Пустые кавычки `""` — пустая строка, в ней нет ни одного символа.

Внутри строки обратная косая черта начинает особые сочетания. Самое нужное — `\n`, перевод строки вывода:

```python
print("Первая строка\nВторая строка")
```

```
Первая строка
Вторая строка
```

## Длина и индексы

Сколько в строке символов, говорит функция `len` (от length — «длина»). Пробелы и знаки препинания тоже считаются: `len("Привет, мир!")` даёт `12`, а `len("")` — `0`.

У каждого символа строки есть номер — <Term id="index">индекс</Term>. Символ получают, написав индекс в квадратных скобках: `s[0]`. **Нумерация начинается с нуля.** Можно считать и с конца — отрицательными индексами:

<div className="table-scroll">

| Символ | P | y | t | h | o | n |
|---|---|---|---|---|---|---|
| Индекс | 0 | 1 | 2 | 3 | 4 | 5 |
| С конца | −6 | −5 | −4 | −3 | −2 | −1 |

</div>

```python
s = "Python"
print(s[0], s[5], s[-1], len(s))
```

```
P n n 6
```

Первый символ — `s[0]`, последний — `s[len(s) - 1]` или короче `s[-1]`. Индекс `s[6]` уже за пределами строки: Python остановится с ошибкой `IndexError: string index out of range`.

<Callout kind="warning" title="Ловушка: «первый» — это нулевой">
Привычка считать с единицы приводит к ошибке на один символ: `s[1]` — это **второй** символ. Самый последний индекс на единицу меньше длины. Если сомневаетесь, нарисуйте строку с номерами, как в таблице выше.
</Callout>

## Срез — кусок строки

Чтобы взять не один символ, а кусок, пишут срез `s[a:b]`: символы с индекса `a` **до** индекса `b`, не включая сам `b`.

```python
s = "Python"
print(s[1:4])
print(s[:2])
print(s[2:])
```

```
yth
Py
thon
```

- `s[1:4]` — символы с индексами 1, 2 и 3; длина куска — `4 - 1 = 3`.
- Если не указать начало, срез идёт с самого начала: `s[:2]` — первые два символа.
- Если не указать конец — до самого конца: `s[2:]` — всё, кроме первых двух.

Конец не включается намеренно: тогда `s[:2] + s[2:]` в точности даёт всю строку. Предскажите, что даст `s[-3:]`, и проверьте по таблице индексов. Другие возможности срезов, например шаг, разберём в разделе «Коллекции» вместе со списками.

## Строку нельзя изменить

Попробуем заменить первую букву:

```python
s = "Python"
s[0] = "J"
```

```
TypeError: 'str' object does not support item assignment
```

Строки **неизменяемы**: созданную строку нельзя поправить на месте. Можно только собрать новую строку и привязать к ней имя:

```python
s = "Python"
s = "J" + s[1:]
print(s)
```

```
Jython
```

Строка `"Python"` при этом не изменилась — просто имя `s` теперь указывает на другую строку. Это уже знакомое правило присваивания: имя перепривязывается к новому значению.

</Page>

## Склеивание

Для строк знак `+` означает склеивание: `"кот" + "ик"` даёт `"котик"`. Склеить строку с числом нельзя: `"Итого: " + 150` остановится с ошибкой `TypeError`. Python не угадывает, хотите вы получить текст или число. Число можно превратить в строку уже знакомой функцией `str`: `"Итого: " + str(150)`. Но есть способ удобнее.

## f-строки

<Term id="f-string">f-строка</Term> — строка с буквой `f` перед кавычками. Всё, что внутри неё стоит в фигурных скобках, Python вычисляет и подставляет в текст, остальное остаётся как есть.

```python
name = "Аня"
age = 20
print(f"{name}, через год вам будет {age + 1}")
```

```
Аня, через год вам будет 21
```

В скобках может быть любое выражение: имя, вычисление, вызов функции. Тип значения неважен — f-строка сама превратит его в текст.

После выражения можно через двоеточие указать формат. Самый нужный — число знаков после точки: `:.2f` означает «дробное число (f) с двумя знаками после точки».

```python
price = 49.9
count = 3
print(f"Итого: {price * count:.2f} руб.")
print(f"{2 / 3:.2f}")
```

```
Итого: 149.70 руб.
0.67
```

Формат меняет только вывод: само значение `2 / 3` не округляется. Именно так результат и выводят — округлять в середине вычислений, как мы говорили в прошлой теме, не нужно. Предскажите, что выведет `f"{10 / 4:.2f}"`.

## Функции, приписанные к значению

У строк есть свои функции — <Term id="method">методы</Term>. Метод вызывают через точку после значения: `s.upper()`. Точка читается как «у этой строки возьми действие upper». Вот самые нужные:

```python
name = "  Анна Петрова  "
print("[" + name.strip() + "]")
print("Анна".lower(), "Анна".upper())
print("8-912-345-67-89".replace("-", ""))
print(float("3,5".replace(",", ".")))
```

```
[Анна Петрова]
анна АННА
89123456789
3.5
```

- `strip()` убирает пробелы и переводы строк по краям. Пользователи часто случайно ставят лишний пробел — `strip()` спасает от этого.
- `lower()` и `upper()` переводят все буквы в нижний и верхний регистр. Удобно сравнивать ответы без учёта регистра.
- `replace(old, new)` заменяет каждое вхождение `old` на `new`. Последняя строка кода — тот самый способ, который мы обещали, когда разбирали `float`: заменить запятую на точку, прежде чем вызывать `float`.

Ещё один метод, `split()`, разрезает строку на части по пробелам. Он вернёт список — списки будут в следующем разделе.

<Callout kind="warning" title="Ловушка: метод не меняет строку">
Строки неизменяемы, поэтому методы **возвращают новую строку**, а исходную не трогают. Результат `s.upper()`, который ни к какому имени не привязали, просто теряется. Правильно: `s = s.upper()`.
</Callout>

## Есть ли подстрока

Слово `in` проверяет, встречается ли одна строка внутри другой, и отвечает `True` или `False`:

```python
print("кот" in "котлета")
print("Кот" in "котлета")
```

```
True
False
```

Регистр важен: `"Кот"` с большой буквы не найден. Если регистр не должен влиять, приведите обе строки к одному: `text.lower()`.
