## Загадка про x = x + 1

На уроке алгебры равенство x = x + 1 не имеет решений: число не может быть равно самому себе плюс один. А в программах такая строка кода встречается на каждом шагу и прекрасно работает. Значит, знак `=` в Python означает что-то другое. Чтобы понять что, начнём с того, с чем вообще работает программа.

Программа работает со <Term id="value">значениями</Term>: `5`, `3.5`, `"кот"`. Значения соединяют знаками операций:

```python
print(2 + 3 * 4)
print("кот" + "ик")
```

```
14
котик
```

Запись `2 + 3 * 4` — это <Term id="expression">выражение</Term>: комбинация значений, имён и операций, которую Python вычисляет, получая одно значение. Здесь получится `14`. Одно число `5` — тоже выражение, самое простое.

Часть программы, которая что-то делает, называется инструкцией. Например, `price = 250` — инструкция: она запоминает значение под именем. Выражение отвечает на вопрос «чему это равно?», инструкция — на вопрос «что сделать?».

</Page>

## Имена

Значение, которое не запомнили, пропадает сразу после вычисления. Чтобы пользоваться им дальше, ему дают имя:

```python
price = 250
count = 3
total = price * count
print(total)
```

```
750
```

<Theorem kind="definition" title="Переменная"
  formal="Переменная — это имя, которое ссылается на значение."
  source="A. Downey, «Think Python», 3rd ed., гл. 2 «Variables and Statements»">

<Term id="variable">Переменная</Term> — это имя, которое указывает на значение. Чаще мы будем говорить просто «имя» — это то же самое. Представьте ярлык на верёвочке: ярлык `price` привязан к числу 250. Само число — отдельно, ярлык только на него показывает. На одно значение могут указывать несколько имён; что из этого следует, подробно разберём в теме «Изменяемые и неизменяемые значения» раздела «Коллекции».

</Theorem>

Привязывает имя к значению <Term id="assignment">присваивание</Term> — инструкция со знаком `=`.

<Theorem kind="rule" title="Как выполняется присваивание"
  formal="Инструкции присваивания (пере)привязывают имена к значениям: инструкция вычисляет выражение справа и привязывает получившееся значение к имени слева."
  source="Python Language Reference, 7.2 «Assignment statements» (сокращено)">

Присваивание выполняется **в два шага**:

1. Сначала полностью вычисляется **правая** часть — выражение после `=`.
2. Потом имя слева **привязывается** к получившемуся значению. Если имя уже указывало на что-то другое, теперь оно указывает на новое.

</Theorem>

Теперь загадка решается. `x = x + 1` читается не «x равно x плюс один», а «вычисли `x + 1` и привяжи имя `x` к результату». Пусть `x` указывает на 5. Шаг 1: `x + 1` даёт 6. Шаг 2: `x` теперь указывает на 6. Знак `=` в Python — это «присвоить», а не «равно». Для вопроса «равно ли?» есть знак `==`, его вы встретите в разделе об условиях.

Пройдите код по шагам. Справа — таблица: слева имена, справа значения, на которые они указывают. Перед каждым шагом предскажите, что в ней изменится.

<Trace code={`x = 5
y = x
x = x + 1
print(x, y)`} />

Строка кода `y = x` не прикрепляет `y` к `x` навсегда. Она вычисляет правую часть — значение, на которое сейчас указывает `x`, это 5, — и привязывает `y` к нему. Когда потом `x` привязывают к 6, `y` по-прежнему указывает на 5. Программа выведет `6 5`.

<Callout kind="warning" title="Имя указывает на значение, а не на формулу">
После `y = x + 1` имя `y` указывает на **готовое число**, а не на «формулу x + 1». Если потом изменить `x`, `y` не пересчитается сам. Формулы, которые пересчитываются, бывают в электронных таблицах, но не в присваивании.
</Callout>

## Поменять местами

Задача: `a` и `b` указывают на 1 и 2. Нужно, чтобы `a` указывало на 2, а `b` — на 1. Первое, что приходит в голову, — две строки кода `a = b` и `b = a`. Предскажите вывод, потом проверьте по шагам:

<Trace code={`a = 1
b = 2
a = b
b = a
print(a, b)`} />

Выведется `2 2`. На третьей строке кода `a` привязали к 2 — и на единицу больше не указывает ни одно имя, она потеряна. Четвёртая строка кода привязывает `b` к тому, на что сейчас указывает `a`, то есть снова к 2.

Решение — сначала привязать к единице ещё одно, временное имя, чтобы она не потерялась:

<Trace code={`a = 1
b = 2
temp = a
a = b
b = temp
print(a, b)`} />

Теперь вывод `2 1`. Этот разбор — образец того, как читать любой код: <Mark>строка за строкой, после каждой записывая, на что указывает каждое имя</Mark>. Это называется *трассировкой*, и в каждой теме дисциплины будут задачи на неё.

</Page>

## Правила

Без них Python не поймёт программу:

- имя состоит из букв, цифр и знака подчёркивания `_`;
- не может начинаться с цифры: `2x` — ошибка;
- не может содержать пробелы и дефисы: `my name` и `my-name` — ошибки;
- регистр важен: `name`, `Name` и `NAME` — три разных имени;
- нельзя брать ключевые слова — слова самого языка: `if`, `for`, `while`, `def`, `class`, `import`, `True` и ещё около тридцати.

## Обычаи

О них договорились программисты на Python (руководство по стилю PEP 8):

- маленькие латинские буквы, слова через подчёркивание: `total_price`, `user_name` — это стиль snake_case, «змеиный регистр»;
- имя говорит, на что оно указывает: `price` лучше, чем `p`;
- русские буквы в именах Python разрешает, но так не принято.

<Callout kind="warning" title="Ловушка: sum = 0">
`print`, `input`, `type`, а позже `len`, `sum`, `max`, `str` — встроенные имена: Python заранее привязал их к готовым функциям. Присваивание может перепривязать и их, Python не запретит. После `print = "Привет"` строка кода `print("Мир")` упадёт с ошибкой `TypeError: 'str' object is not callable` — имя `print` теперь указывает на текст, а текст нельзя вызвать (как читать такие сообщения — в теме 5). Самая частая версия этой ошибки — назвать сумму `sum`, а максимум — `max`. Называйте так: `total`, `max_price`.
</Callout>

## У каждого значения есть тип

Сложите два числа — получится число. Сложите два текста — они склеятся. А текст и число Python сложить откажется. Что можно делать со значением, зависит от его типа.

<Theorem kind="definition" title="Тип"
  formal="Тип объекта определяет, какие операции он поддерживает, и задаёт возможные значения для объектов этого типа."
  source="Python Language Reference, 3.1 «Objects, values and types»">

<Term id="data-type">Тип</Term> — это вид значения: целое число, дробное число, текст и так далее. Тип решает две вещи: какие значения возможны и какие операции с ними разрешены.

</Theorem>

Четыре типа, с которых всё начинается:

<div className="table-scroll">

| Тип | Что это | Примеры |
|---|---|---|
| `int` | целое число | `5`, `-3`, `0` |
| `float` | дробное число | `3.5`, `2.0`, `-0.25` |
| `str` | строка, то есть текст | `"кот"`, `"5"`, `""` |
| `bool` | логическое значение | `True`, `False` |

</div>

<Callout kind="remember" title="Слово «объект»">
В сообщениях об ошибках и в документации вы встретите слово «объект»: так Python называет значение (`'str' object` — «значение-строка»). К «объекту» из машинного обучения (строке таблицы данных) это отношения не имеет.
</Callout>

Узнать тип значения можно функцией `type`:

```python
print(type(5))
print(type(5.0))
print(type("5"))
print(type(True))
```

```
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
```

Слово `class` здесь означает «тип». `5`, `5.0` и `"5"` — три **разных** значения трёх разных типов. Тип есть у значения, а не у имени: после `x = 5` и `x = "пять"` имя `x` указывает уже на строку. Python это разрешает, но читателю кода так легко запутаться. Числа и строки подробно разберём в следующих двух темах, `bool` — в разделе об условиях.

</Page>

## Преобразование типов

Из первой темы вы помните: `input()` всегда возвращает строку. Чтобы считать с введённым числом, строку нужно преобразовать. Для этого есть функции с именами типов:

- `int("42")` даёт целое `42`;
- `float("2.5")` даёт дробное `2.5`;
- `str(42)` даёт строку `"42"`.

Отсюда главная связка для ввода чисел:

```python
a = int(input())
b = int(input())
print(a + b)
```

Сначала выполняется `input()` и возвращает строку, например `"7"`. Затем `int(...)` превращает её в число 7, и уже число привязывается к имени `a`. Предскажите вывод для ввода 7 и 5, а потом сравните с программой из первой темы, где получалось `"75"`. Здесь будет `12`.

`int` прощает пробелы по краям: `int(" 42 ")` даёт `42`. Но если в строке не целое число, программа остановится с ошибкой (как читать такие сообщения — в теме 5):

```python
n = int("3.5")
```

```
ValueError: invalid literal for int() with base 10: '3.5'
```

<Callout kind="warning" title="Ловушка: запятая вместо точки">
Python понимает в дробях только точку: `float("3,5")` даст `ValueError: could not convert string to float: '3,5'`. Если данные приходят с запятой, её сначала заменяют на точку — как это сделать, увидим в теме о строках.
</Callout>

## Формулировки темы

- **Переменная** — имя, которое указывает на значение. Простыми словами: ярлык на значении, а не коробка с ним.
- **Присваивание** — сначала вычисляется правая часть, потом имя слева привязывается к результату. Простыми словами: `x = x + 1` — «вычисли и перепривяжи», а не «равно».
- **Тип** — определяет, какие значения возможны и какие операции разрешены. Простыми словами: число складывается с числом, текст склеивается с текстом, а сложить текст с числом нельзя.
