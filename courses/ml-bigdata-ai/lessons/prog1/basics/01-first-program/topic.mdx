## Одна строка кода

Вот программа на Python:

```python
print("Привет, мир!")
```

Она выводит:

```
Привет, мир!
```

Код в этом курсе выполняется прямо в браузере, ничего устанавливать не нужно. Пройдите программу по шагам: подсвеченная строка кода — та, что выполнится следующей, внизу — то, что программа уже вывела.

<Trace code={`print("Привет, мир!")
print("Пока!")`} />

Из чего состоит строка кода `print("Привет, мир!")`:

- `print` — *функция*: готовая команда с именем. Эта выводит на экран то, что ей передали.
- Круглые скобки после имени — *вызов* функции: «выполни сейчас».
- `"Привет, мир!"` — текст в кавычках. Кавычки говорят Python: это не команда, а данные, выведи их как есть. Подойдут и двойные, и одинарные: `'Привет'`.

Python выполняет программу **сверху вниз**, по одной инструкции. Каждый `print` выводит текст с новой строки:

```python
print("Раз")
print(2 + 3)
print("2 + 3")
```

```
Раз
5
2 + 3
```

Без кавычек `2 + 3` — вычисление, и Python выводит результат. В кавычках — просто пять символов текста (вместе с пробелами), Python их не вычисляет. Замените в первом `print` текст на `2 * 3` без кавычек и предскажите вывод.

Если передать `print` несколько значений через запятую, она выведет их через пробел:

```python
print("Сумма:", 2 + 3, "руб.")
```

```
Сумма: 5 руб.
```

Текст после `#` до конца строки кода — комментарий. Python его пропускает, комментарии пишут для людей: `print("Привет")  # поздоровались`.

## Почему Python

В Курсе 0 мы договорились: внутри любой модели машинного обучения работает обычная <Term id="program">программа</Term>. Данные читает программа, модель обучает программа, ответы пользователю отдаёт тоже программа. В машинном обучении такие программы пишут в основном на <Term id="python">Python</Term>:

- **его легко читать** — код читают гораздо чаще, чем пишут, а вы будете много читать чужой код;
- **вокруг него вырос весь инструментарий ML** — библиотеки для таблиц, вычислений и нейросетей пишутся в первую очередь для Python;
- **он один на всём пути** — анализ данных, обучение моделей, скрипты, проверки.

Язык придумал голландский программист Гвидо ван Россум, первая версия вышла в 1991 году, а название взято из британского комедийного шоу «Летающий цирк Монти Пайтона».

## Что даст дисциплина

«Основы Python» — не справочник по всему языку и ещё не машинное обучение, а ремесло, на котором стоит всё остальное. После дисциплины вы:

- сами пишете программы до сотни строк: прочитать данные — обработать — вывести ответ;
- по шагам предсказываете, что сделает код, ещё до запуска;
- собираете программу из нескольких частей и проверяете каждую своими проверками, а если что-то сломалось — находите причину по сообщению об ошибке.

## Программа спрашивает

Функция `input` получает данные от пользователя: программа останавливается и ждёт, пока он введёт строку и нажмёт Enter.

```python
name = input("Как вас зовут? ")
print("Привет,", name)
```

Если ввести `Аня`, на экране будет:

```
Как вас зовут? Аня
Привет, Аня
```

Текст в скобках у `input` — подсказка: она выводится перед вводом. Запись `name = ...` запоминает введённое под именем `name`; как это работает, разберём в следующей теме. Ввод для этого прохода по шагам уже подготовлен — строка `Аня`:

<Trace code={`name = input("Как вас зовут? ")
print("Привет,", name)`} stdin="Аня" />

<Theorem kind="rule" title="input() всегда возвращает строку"
  formal="Функция input() выводит подсказку prompt (если она передана), читает строку из ввода, отбрасывает перевод строки в конце и возвращает результат как строку."
  source="Документация Python, Built-in Functions: input()">

`input()` читает **одну строку ввода** и отдаёт её как текст. Даже если пользователь набрал цифры, программа получает текст из цифр, а не число.

</Theorem>

Пусть пользователь ввёл `2` и `3`, каждое отдельной строкой. Предскажите вывод, прежде чем читать дальше:

```python
a = input()
b = input()
print(a + b)
```

```
23
```

Для текста `+` означает «склеить», поэтому из `"2"` и `"3"` получилось `"23"`, а не `5`. Как превратить текст в число, разберём в следующей теме. Пока запомните: <Mark>всё, что пришло из input(), — текст</Mark>.

## Как читать условие задачи

В практике вы будете решать задачи с автоматической проверкой. Условие отвечает на три вопроса:

1. **Что подаётся на вход** — сколько строк ввода и что в каждой. Каждая строка ввода — один вызов `input()`.
2. **Что нужно вывести** — точный формат: слова, знаки препинания, порядок строк вывода.
3. **Примеры** — пары «ввод → ожидаемый вывод». Прежде чем писать код, проверьте себя на них вручную.

Например: «На вход подаётся имя. Выведите `Привет, <имя>!`». Ввод `Аня` — вывод `Привет, Аня!`.

В задаче есть кнопки «Запустить» (выполнить программу на своём вводе), «По шагам» и «Проверить» — прогнать программу на тестах. <Term id="test-case">Тест</Term> — заранее подготовленный ввод вместе с ответом, который программа обязана выдать.

Пусть вы написали `print("Привет,", name)` и нажали «Проверить». Результат выглядит так:

```
Пройдено тестов: 0 из 2.
Пример 1
  Ввод:      Аня
  Ожидалось: Привет, Аня!
  Получено:  Привет, Аня
```

Сравните «Ожидалось» и «Получено» посимвольно: не хватает восклицательного знака. Вывод сравнивается **точно**: другая буква или лишняя пустая строка между строками вывода — уже несовпадение. Не важны только пробелы в конце строк вывода и пустые строки в самом конце. Подсказка в `input("...")` проверке не мешает: при проверке её текст в вывод не попадает.

Часть тестов скрыта: вы видите только, что они не прошли. Обычно это граничные случаи — ноль, пустой ввод, очень большое число. Перечитайте условие и подумайте, какие входы ещё возможны.

<Callout kind="remember">
Тест не прошёл — значит, программа выдала не то, что требует условие. Это не оценка вас, а подсказка: в «Получено» видно, что именно пошло не так.
</Callout>

## Проверка через assert

Иногда задача просит не целую программу, а одну свою функцию, — писать их вы научитесь в разделе «Функции». Проверяют такие задачи не по выводу, а инструкцией `assert`. Её важно уметь читать уже сейчас: так выглядят тесты.

<Theorem kind="rule" title="Инструкция assert"
  formal="Инструкция assert выражение вызывает исключение AssertionError, если выражение ложно. Она служит для вставки в программу отладочных проверок."
  source="Python Language Reference, 7.3 «The assert statement»">

`assert` переводится как «утверждаю». После слова пишут утверждение, которое должно быть верным. Верно — программа молча идёт дальше. Неверно — программа останавливается с ошибкой `AssertionError`, и тест провален. Что такое исключения и как читать ошибки, разберём в теме 5.

</Theorem>

Пример теста к задаче, где нужно написать функцию `square` — квадрат числа. Пока считайте `square(3)` просто командой, которая должна вернуть 9:

```python
assert square(3) == 9, "square(3) должно вернуть 9"
```

Читается так: «Утверждаю, что `square(3)` равно 9. Если нет — сообщи: square(3) должно вернуть 9». Знак `==` означает «равно ли?», а текст после запятой — сообщение, которое вы увидите при провале. Если функция вернёт 6, в результатах проверки появится именно эта фраза, и сразу ясно, на каком входе ошибка.

Без сообщения `assert` тоже работает, просто при провале вы увидите только `AssertionError`:

```python
assert 2 + 2 == 4   # верно — ничего не происходит
assert 2 + 2 == 5   # неверно — AssertionError
```
