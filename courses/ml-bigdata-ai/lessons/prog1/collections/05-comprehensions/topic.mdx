## Знакомый шаблон

Цены из чека пришли строкой. Чтобы с ними можно было считать, каждую часть превращают в число — шаблон накопителя со списком:

```python
parts = "89 45 320".split()
prices = []
for p in parts:
    prices.append(int(p))
print(prices, sum(prices))
```

```
[89, 45, 320] 454
```

Три строки кода ради одной мысли: «список из `int(p)` для каждого `p` в `parts`». Python позволяет записать эту мысль почти дословно:

```python
parts = "89 45 320".split()
prices = [int(p) for p in parts]
print(prices, sum(prices))
```

```
[89, 45, 320] 454
```

<Theorem kind="definition" title="Списковое включение"
  formal="Списковое включение — квадратные скобки, внутри которых стоит выражение, за ним предложение for, а затем ноль или больше предложений for или if. Результат — новый список: выражение вычисляется на каждом шаге следующих за ним предложений for и if, и его значения собираются по порядку."
  source="Python Tutorial, 5.1.3 «List Comprehensions» (пересказ)">

<Term id="list-comprehension">Списковое включение</Term> (англ. list comprehension) — короткая запись шаблона «пустой список, цикл, `append`»: `[выражение for имя in последовательность]`. Сначала — что положить в список, потом заголовок цикла без двоеточия.

</Theorem>

Включение читается почти как обычная фраза: `[int(p) for p in parts]` — «`int(p)` для каждого `p` из `parts`». Соответствие с циклом точное:

- `prices = []` и `prices.append(...)` — это сами квадратные скобки;
- `for p in parts:` — та же часть `for p in parts`;
- `int(p)` — то, что стояло в скобках у `append`.

В работе эту запись чаще называют по-английски — «компрехеншен». В русских статьях встречается и «генератор списка», но в Python генераторы — другое понятие; о них — в дисциплине «Инженерный Python».

## Отобрать нужное

Второй частый шаблон — собрать в список только подходящие элементы. Морозные дни за неделю:

```python
temps = [3, -2, 5, -7, 1]
cold = [t for t in temps if t < 0]
print(cold)
```

```
[-2, -7]
```

`if` в конце — это условие из тела цикла: элемент попадает в список, только если условие истинно. В виде цикла это `for t in temps:`, внутри `if t < 0:` и `cold.append(t)`.

Предскажите, к каким значениям по очереди будет привязано имя `t` и что окажется в `cold`. Потом пройдите программу по шагам:

<Trace>

```python
temps = [3, -2, 5, -7, 1]
cold = [t for t in temps if t < 0]
print(cold)
```

</Trace>

Имя `t` живёт только во время работы включения, как локальное имя функции: `print(t)` после такой программы даст `NameError`. После обычного `for` переменная цикла остаётся — здесь включение ведёт себя иначе.

Отбор и преобразование можно соединить: `[abs(t) for t in temps if t < 0]` даёт `[2, 7]` — сила мороза в градусах. Порядок частей всегда один: что положить, откуда брать, какие брать.

## if в конце и if…else в начале

Иногда нужно не отбросить элемент, а положить вместо него что-то другое. Тогда в начале стоит условное выражение, которое вы уже знаете, — `a if условие else b`:

```python
temps = [3, -2, 5, -7, 1]
print(["мороз" if t < 0 else "без мороза" for t in temps])
```

```
['без мороза', 'мороз', 'без мороза', 'мороз', 'без мороза']
```

<Theorem kind="rule" title="Где стоит if во включении"
  formal="if после for отбирает элементы: элемент, для которого условие ложно, в результат не попадает. Условное выражение «a if условие else b» на месте выражения вычисляет значение для каждого элемента: длина результата равна числу элементов. Запись if…else после for — синтаксическая ошибка."
  source="Python Tutorial, 5.1.3 «List Comprehensions»; Python Language Reference, 6.12 «Conditional expressions» (пересказ)">

- `[x for x in data if условие]` — **отбор**: в результате только подходящие элементы, список может стать короче.
- `[a if условие else b for x in data]` — **замена**: для каждого элемента ровно одно значение, длина та же.
- `else` после `for` писать нельзя: `[t for t in temps if t < 0 else 0]` — `SyntaxError: invalid syntax`.

</Theorem>

## Фигурные скобки

Так же собирают словарь и множество — только скобки фигурные.

```python
words = ["Чай", "сыр", "Сыр", "молоко"]
print({w: len(w) for w in words})
print(sorted({w.lower() for w in words}))
```

```
{'Чай': 3, 'сыр': 3, 'Сыр': 3, 'молоко': 6}
['молоко', 'сыр', 'чай']
```

- **Включение словаря** `{ключ: значение for …}` — в начале пара через двоеточие. Если ключ повторится, останется последнее значение, как при обычном `d[key] = value`.
- **Включение множества** `{выражение for …}` — одно выражение, без двоеточия. Повторы отбрасываются: «Сыр» и «сыр» после `lower()` стали одним элементом.

Справочник «товар → цена» из таблицы — списка словарей:

```python
products = [
    {"name": "чай", "price": 150},
    {"name": "мёд", "price": 300},
]
price_of = {p["name"]: p["price"] for p in products}
print(price_of)
```

```
{'чай': 150, 'мёд': 300}
```

Перебирать можно и пары. Например, цены со скидкой 10% для всего справочника: `items()` даёт пары «ключ, значение», а распаковка раскладывает их по двум именам, как в заголовке обычного `for`:

```python
price_of = {"чай": 150, "мёд": 300}
print({name: price * 0.9 for name, price in price_of.items()})
```

```
{'чай': 135.0, 'мёд': 270.0}
```

## Обещанная запись any(s == 0 for s in sales)

Когда вы знакомились с `any`, вы видели запись `any(s == 0 for s in sales)` — «есть ли день с нулевой выручкой». Теперь её можно прочитать: это включение без квадратных скобок.

```python
sales = [1200, 0, 850]
print(any(s == 0 for s in sales))
print(all(s > 100 for s in sales))
print(sum(s * 2 for s in sales))
```

```
True
False
4100
```

Если включение — единственный аргумент функции, квадратные скобки можно не писать: хватает скобок вызова `any(...)`. Это <Term id="generator-expression">генераторное выражение</Term>: оно не собирает список, а выдаёт значения по одному, по мере перебора, — как `zip` и `enumerate`. Как и их, перебрать его можно только один раз. Функции `sum`, `any` и `all` берут значения по очереди, и целый список в памяти не нужен; `any` к тому же останавливается на первом истинном значении и дальше не смотрит. Как такие выражения устроены внутри, разберём в дисциплине «Инженерный Python».

## Включение — для нового списка

Включение отвечает на вопрос «какой список получить». Если цель — действие, нужен обычный цикл. ИИ-ассистент иногда пишет `[print(x) for x in names]`: печать сработает, но попутно соберётся ненужный список из `None`, которые вернул каждый вызов `print`. Читатель кода будет искать, где этот список нужен. Пишите `for x in names:` и в теле `print(x)`.

Включение не делает программу заметно быстрее — его выбирают ради читаемости.

## Два for подряд

В одном включении может быть несколько `for`. Они идут в том же порядке, что вложенные циклы: внешний — первым.

```python
table = [[1, 2], [3, 4]]
flat = [x for row in table for x in row]
print(flat)
```

```
[1, 2, 3, 4]
```

Здесь `row` — строка таблицы, то есть внутренний список (не путайте с типом `str`). Тот же результат даёт цикл:

```python
flat = []
for row in table:
    for x in row:
        flat.append(x)
```

Читается так: «`x` — для каждой строки таблицы `row` из `table`, и в ней для каждого `x`».

Помните ловушку `[[0] * 3] * 3` — три псевдонима одной строки таблицы? Таблицу нулей 3 × 3 правильно собирает включение: `[[0] * 3 for _ in range(3)]`. Выражение `[0] * 3` вычисляется на каждой итерации заново, и каждая строка таблицы — новый список. Имя `_` — обычное имя; так по договорённости называют переменную цикла, значение которой не нужно.

<Mark>Включение хорошо, пока оно читается одной фразой.</Mark> Два `for` — уже предел. Если нужно несколько действий, вложенные условия или включение не помещается в одну строку кода, обычный цикл понятнее: его легче прочитать и проследить по шагам.
