## Имя без скобок

Вы уже знаете ловушку: `print(with_discount)` выводит не результат, а саму функцию — `<function with_discount at 0x…>`. Скобки — это вызов, а имя без скобок указывает на значение, как любое другое имя. К этому значению можно привязать другое имя, его можно передать аргументом.

```python
def with_discount(price, percent):
    return price - price * percent / 100

sale = with_discount
print(sale(1000, 10), sale is with_discount)
```

```
900.0 True
```

`sale = with_discount` — обычное присваивание без вызова: теперь `sale` и `with_discount` — псевдонимы одной и той же функции, поэтому `is` даёт `True`. Вызвать её можно через любое из имён.

## Функция в аргументе

Сделать что-то с каждым элементом списка — частая задача. Что именно делать, можно передать аргументом. Предскажите вывод, потом пройдите по шагам:

<Trace>

```python
def half(x):
    return x / 2

def apply_to_all(f, values):
    return [f(x) for x in values]

print(apply_to_all(half, [100, 30]))
```

</Trace>

В блоке `apply_to_all()` имя `f` указывает на функцию `half`: как всегда, параметр — новое имя для того же значения. Вызов `f(x)` — это вызов `half`. Передайте другую функцию — `apply_to_all(round, [2.6, 3.4])` даст `[3, 3]`, а саму `apply_to_all` переписывать не придётся.

<Theorem kind="definition" title="Функция высшего порядка"
  formal="Функция высшего порядка — функция, которая принимает другую функцию как аргумент или возвращает функцию как значение."
  source="J. DeNero, «Composing Programs» (курс CS61A, UC Berkeley), 1.6 «Higher-Order Functions» (пересказ)">

<Term id="higher-order-function">Функция высшего порядка</Term> — функция, которая работает с другой функцией как со значением. `apply_to_all` — такая: она получает `f` и сама решает, когда и к чему её применить. Возвращать функции вы научитесь в дисциплине «Инженерный Python»; здесь нам хватит функций, которые принимают функцию.

</Theorem>

</Page>

## Лишние скобки

Самая частая ошибка — вызвать функцию там, где её нужно передать:

```python
def half(x):
    return x / 2

def apply_to_all(f, values):
    return [f(x) for x in values]

print(apply_to_all(half(), [100, 30]))
```

```
Traceback (most recent call last):
  File "C:\work\prices.py", line 7, in <module>
    print(apply_to_all(half(), [100, 30]))
                       ^^^^^^
TypeError: half() missing 1 required positional argument: 'x'
```

Функции `half` не хватило аргумента: аргументы вычисляются до вызова, и Python сначала попытался выполнить `half()` — без числа. Даже если бы вызов удался, в `apply_to_all` попал бы его результат, а не функция.

## Маленькая функция без имени

Если функция нужна в одном месте и умещается в одно выражение, есть короткая запись:

```python
def apply_to_all(f, values):
    return [f(x) for x in values]

print(apply_to_all(lambda x: x * 2, [1, 2, 3]))
```

```
[2, 4, 6]
```

`lambda x: x * 2` — «функция от `x`, которая возвращает `x * 2`». До двоеточия — параметры, после — одно выражение. Слово `return` не пишут: значение выражения возвращается само.

<Term id="lambda">lambda</Term>-выражение создаёт функцию без имени — самую обычную функцию: `type(lambda x: x)` даёт `<class 'function'>`, её можно вызвать, передать, привязать к ней имя. Отличий от `def` два. Тело — только одно выражение: никаких инструкций, то есть циклов, присваиваний и блоков `if`, а условное выражение `a if условие else b` можно. И нет имени: при выводе Python пишет `<lambda>` вместо него. Параметров может быть несколько: `lambda a, b: a + b`.

Привязывать имя к `lambda` (`double = lambda x: x * 2`) PEP 8 не советует: если функции нужно имя, пишите `def` — будет понятное имя в traceback и место для строки документации. `lambda` хороша там, где функцию сразу передают аргументом, — например, в сортировке.

## По какому признаку сортировать

`sorted` и `sort` вы уже знаете: числа они расставляют по возрастанию. А если нужно расставить слова по длине? Передайте функцию, которая для каждого элемента говорит, по чему его сравнивать:

```python
words = ["молоко", "чай", "сыр", "хлеб"]
print(sorted(words, key=len))
print(words)
```

```
['чай', 'сыр', 'хлеб', 'молоко']
['молоко', 'чай', 'сыр', 'хлеб']
```

`key=len` — именованный аргумент, и его значение — функция `len`, без скобок. Сами слова не изменились: сравнивались длины, а в результат попали исходные элементы.

<Theorem kind="definition" title="Ключ сортировки"
  formal="Параметр key функции sorted и метода list.sort задаёт функцию одного аргумента, которую вызывают для каждого элемента списка перед сравнениями. Элементы упорядочиваются по возвращённым значениям — ключам сортировки."
  source="Python HOWTO «Sorting Techniques», раздел «Key Functions»; Python Standard Library, «Built-in Functions», sorted (пересказ)">

<Term id="sort-key">Ключ сортировки</Term> — значение, по которому сравнивают элемент: для `key=len` ключ слова «молоко» — 6. Порядок задают ключи, а в результат попадают сами элементы, не ключи. Это не ключ словаря: слово то же, смысл другой — здесь ключ задаёт, по чему сравнивать.

</Theorem>

Функция-ключ — обычная функция, и её вызовы видны по шагам. Предскажите: сколько раз будет вызвана `length` для трёх слов? Потом проверьте:

<Trace>

```python
def length(word):
    return len(word)

words = ["сыр", "молоко", "чай"]
print(sorted(words, key=length))
```

</Trace>

Три раза: функция из аргумента `key` вызывается ровно один раз для каждого элемента, а дальше сортировка сравнивает уже готовые ключи.

## Строки по алфавиту — не совсем по алфавиту

Строки сравниваются посимвольно, по номерам символов в таблице Юникода — их называют кодовыми точками. У заглавных букв номера меньше, чем у строчных, а у «ё» — больше, чем у «я». Подробнее о таблице — в теме о файлах и кодировках раздела «Текст и файлы».

```python
print(sorted(["Яблоко", "арбуз", "Банан"]))
print(sorted(["ёж", "яблоко", "енот"]))
print(sorted(["Яблоко", "арбуз", "Банан"], key=lambda w: w.lower()))
```

```
['Банан', 'Яблоко', 'арбуз']
['енот', 'яблоко', 'ёж']
['арбуз', 'Банан', 'Яблоко']
```

С ключом `lambda w: w.lower()` регистр перестаёт мешать. А слово «ёж» после слова «яблоко» так не исправить — нужен свой ключ, например `lambda w: w.replace("ё", "е")`.

## Список словарей без key не отсортировать

Результаты игры — таблица, список словарей:

```python
players = [
    {"name": "Глеб", "score": 80},
    {"name": "Аня", "score": 95},
    {"name": "Вера", "score": 80},
    {"name": "Борис", "score": 70},
]
print(sorted(players))
```

```
Traceback (most recent call last):
  File "C:\work\game.py", line 7, in <module>
    print(sorted(players))
          ^^^^^^^^^^^^^^^
TypeError: '<' not supported between instances of 'dict' and 'dict'
```

«Операция `<` для двух словарей не поддерживается»: Python не знает, какой игрок «меньше». Ключ сортировки и подсказывает, как сравнивать: по очкам, от большего к меньшему.

```python
ranking = sorted(players, key=lambda p: p["score"], reverse=True)
for p in ranking:
    print(p["name"], p["score"])
```

```
Аня 95
Глеб 80
Вера 80
Борис 70
```

Не путайте: `"score"` — ключ словаря, а `key=` — ключ сортировки; lambda достаёт значение по ключу словаря и отдаёт его как ключ сортировки.

## Равные ключи: порядок сохраняется

У Глеба и Веры по 80 очков, и Глеб остался выше — как был в исходном списке. Это не случайность: сортировка в Python <Term id="stable-sort">устойчивая</Term> — элементы с равными ключами сохраняют свой исходный порядок, в том числе с `reverse=True`.

Если при равенстве очков нужен алфавит, ключом делают кортеж:

```python
ranking = sorted(players, key=lambda p: (-p["score"], p["name"]))
print([p["name"] for p in ranking])
```

```
['Аня', 'Вера', 'Глеб', 'Борис']
```

Кортежи сравниваются поэлементно, как слова по буквам: сначала первые элементы, при равенстве — вторые. `(-80, "Вера")` меньше `(-80, "Глеб")`: строка «Вера» по алфавиту раньше строки «Глеб». Минус разворачивает порядок только по очкам: большие очки дают меньший ключ. Так можно только с числами; строки по убыванию сортируют через `reverse=True`.

Первые три места — срез `ranking[:3]`. Один лучший без сортировки — `max(players, key=lambda p: p["score"])`; у `min` тоже есть `key`. А словарь сортируют по значениям через его пары; `item[1]` — второй элемент пары, цена:

```python
prices = {"чай": 150, "мёд": 300, "хлеб": 45}
by_price = sorted(prices.items(), key=lambda item: item[1])
print(by_price)
print(dict(by_price))
```

```
[('хлеб', 45), ('чай', 150), ('мёд', 300)]
{'хлеб': 45, 'чай': 150, 'мёд': 300}
```

Получается список пар; `dict(...)` снова собирает из них словарь.
