## Одна формула — много копий

Цену со скидкой считают по одной формуле, и в программе эта формула повторяется: `45 - 45 * 10 / 100`, `320 - 320 * 15 / 100`… Если она изменится, придётся править каждую копию. Лучше записать формулу один раз и дать ей имя:

```python
def with_discount(price, percent):
    return price - price * percent / 100

print(with_discount(45, 10))
print(with_discount(320, 15))
```

```
40.5
272.0
```

`def` — «определить функцию», за ним имя и в скобках имена для входных данных. Параметров может и не быть: `def hello():`. После двоеточия с отступом — тело, как у `if` и `for`. `return` — «вернуть»: вычислить выражение и отдать результат туда, откуда функцию вызвали.

<Theorem kind="definition" title="Функция, параметр, аргумент"
  formal="Функция — именованная последовательность инструкций, которая выполняет некоторую операцию; она может принимать аргументы и возвращать результат. Параметры — имена, перечисленные в определении функции; аргументы — значения, которые фактически передают функции при вызове."
  source="A. Downey, «Think Python», 3rd ed., гл. 3 и глоссарий (function); Python FAQ, «What is the difference between arguments and parameters?»">

<Term id="function">Функция</Term> — кусок программы с именем: на входе данные, внутри инструкции, на выходе результат. <Term id="function-parameter">Параметры</Term> — имена в скобках после `def`: `price`, `percent`. <Term id="argument">Аргументы</Term> — значения, которые подставляют при вызове: в `with_discount(45, 10)` это `45` и `10`. Параметр — имя в определении, аргумент — значение, к которому это имя привяжут при вызове.

Раньше мы называли параметром и то, что пишут при вызове. Точнее так: у функции `math.isclose` есть параметр `abs_tol`, а `abs_tol=0.01` в вызове — аргумент.

</Theorem>

<Callout kind="remember" title="def не выполняет тело">
Python выполняет программу сверху вниз. Инструкция `def` лишь привязывает имя к функции, а тело выполняется только при вызове. К моменту вызова инструкция `def` уже должна быть выполнена, иначе будет `NameError`. А в теле функции можно вызывать другую, определённую ниже, — если сам вызов стоит после обеих инструкций `def`.
</Callout>

</Page>

## Вызов по шагам

Первая строка кода ниже — `def`: в блоке «Программа» справа появится имя `with_discount`, а тело пока не выполнится. Каждый вызов получает свой набор имён. Предскажите, на что в конце будет указывать `total`, потом пройдите программу по шагам:

<Trace>

```python
def with_discount(price, percent):
    cut = price * percent / 100
    return price - cut

total = with_discount(1200, 15)
print(total)
```

</Trace>

С началом вызова появляется блок `with_discount()` со своими именами, после `return` он исчезает. Почему имена функции живут отдельно, разберём в следующей теме.

<Theorem kind="rule" title="Что происходит при вызове функции"
  formal="При вызове сначала вычисляются аргументы. Выполнение функции создаёт новый набор локальных имён; параметры привязываются в нём к значениям аргументов — как при присваивании. Инструкция return завершает функцию и возвращает значение; return без выражения, как и функция, дошедшая до конца тела, возвращает None."
  source="Python Tutorial, 4.8 «Defining Functions»; Python Language Reference, 6.3.4 «Calls» (пересказ)">

1. Вычисляются аргументы — все выражения в скобках вызова.
2. Для вызова создаётся свой набор имён. Параметры привязываются к значениям аргументов по порядку (а именованные аргументы — по имени, о них ниже), как при присваивании: `price = 1200`, `percent = 15`. <Mark>Параметр — новое имя для того же значения.</Mark>
3. Тело выполняется сверху вниз до `return` или до конца тела.
4. Вызов заменяется возвращённым значением: дальше Python считает так, будто там с самого начала было написано `1020.0`.

</Theorem>

Аргументы вычисляются до вызова. Если аргумент сам — вызов функции, он выполнится первым.

## Показать или отдать

Задачи с функциями платформа проверяет инструкцией `assert` — той, что вы читали ещё в теме «Первая программа»: `assert area(3, 4) == 12`. Если все проверки с `assert` проходят, программа ничего не выводит. Проверка смотрит на возвращённое значение, и здесь новичок чаще всего ошибается — пишет `print` вместо `return`:

```python
def area_print(width, height):
    print(width * height)

def area(width, height):
    return width * height

a = area_print(3, 4)
b = area(3, 4)
print(a, b)
```

```
12
None 12
```

Первую строку вывода напечатал `print` внутри `area_print`, вторую — `print(a, b)`. `area_print` показала `12` человеку, но программе ничего не отдала. `area` отдала значение программе через `return`. Сложим площади двух комнат: `area_print(3, 4) + area_print(2, 5)` выведет `12` и `10`, а потом упадёт:

```
TypeError: unsupported operand type(s) for +: 'NoneType' and 'NoneType'
```

Оба вызова вернули `None`, а складывать `None` нельзя. `NoneType` — тип значения `None`; о самом `None` — ниже. Проверку с `assert` такая функция не пройдёт, даже если на экране всё верно.

## None — «ничего»

<Term id="none">None</Term> — особое значение «результата нет». Его возвращает функция без `return` или с `return` без выражения. Функция `print` и метод списка `append` тоже возвращают `None`; почему так принято, разберём в следующей теме.

После `result = print("Привет")` проверка `result is None` даёт `True`. Запись `result is None` читается «result — это None». Так и проверяют, а не через `== None`: это советует PEP 8. PEP — документы с правилами языка Python, а PEP 8 — руководство по стилю кода. Чем `is` отличается от `==`, узнаете в теме «Изменяемые и неизменяемые значения» раздела «Коллекции».

## return завершает функцию

То, что отдаёт `return`, — <Term id="return-value">возвращаемое значение</Term> функции. После `return` вызов заканчивается сразу: строки кода ниже не выполняются, даже если `return` стоит внутри цикла, — цикл тоже прерывается. Поэтому для поиска в функции не нужны флаг и `break`:

```python
def has_zero(sales):
    for sale in sales:
        if sale == 0:
            return True
    return False

print(has_zero([1200, 0, 850]), has_zero([500, 900]))  # True False
```

`return False` стоит после цикла: «нет» можно сказать, только просмотрев весь список. Заметьте: `return` — не функция, а инструкция, скобки после него не нужны.

## Аргументов не хватило

Аргументов передают столько, сколько у функции параметров (если у параметров нет значений по умолчанию — о них ниже). Забудем передать процент:

```python
def with_discount(price, percent):
    return price - price * percent / 100

print(with_discount(1200))
```

```
Traceback (most recent call last):
  File "C:\work\shop.py", line 4, in <module>
    print(with_discount(1200))
          ^^^^^^^^^^^^^^^^^^^
TypeError: with_discount() missing 1 required positional argument: 'percent'
```

Снизу вверх: «функции `with_discount()` не хватает обязательного аргумента `percent`», ошибка в строке 4. `positional` — «позиционный»: аргумент для этого параметра можно передать по порядку, без имени (по имени — тоже можно). Лишний аргумент — `takes 2 positional arguments but 3 were given`. В Python 3.13 и новее под строкой вызова могут стоять ещё и знаки `~`.

## Значения по умолчанию и аргументы по имени

Если обычная скидка — 10%, её можно записать прямо в определении:

```python
def with_discount(price, percent=10):
    return price - price * percent / 100

print(with_discount(1200))
print(with_discount(1200, 15))
print(with_discount(percent=50, price=1200))
```

```
1080.0
1020.0
600.0
```

`percent=10` — <Term id="default-value">значение по умолчанию</Term>: если аргумент не передали, параметр привяжется к этому значению. Такие параметры пишут после остальных, иначе Python не примет определение. Значение по умолчанию вычисляется один раз, когда выполняется `def`; почему список в этой роли — ловушка, узнаете в теме «Изменяемые и неизменяемые значения».

В третьем вызове у каждого аргумента указано имя параметра. Такие аргументы называют <Term id="keyword-argument">именованными</Term>: Python сопоставляет их по имени, поэтому порядок именованных аргументов неважен. Обычные, позиционные аргументы идут первыми: `with_discount(1200, percent=15)`. Вы уже встречали именованный аргумент: `print(n, end=" ")`.

<Callout kind="warning" title="Ловушка: имя без скобок">
Скобки — это и есть вызов. `print(with_discount)` выведет не результат, а описание самой функции: `<function with_discount at 0x000001F692FBD6C0>`. В конце — адрес в памяти, у вас он будет другим. Хуже, когда ошибка молчит: если написать `if is_empty:` вместо `if is_empty(cart):` (где `is_empty` — ваша функция проверки корзины), ветка `if` выполнится всегда: сама функция, без вызова, считается истиной.
</Callout>
